# 独立状态轴

归属：PERSONAL_STATEMENT / INTERVIEW_ANSWER / INTERVIEW_QUESTION / TEAM_PROJECT / EDITORIAL / RESEARCH_INFERENCE。
获取：METADATA / CONTENTS / EXCERPT / FULL_FILE。
阅读：UNREAD / LOCATED_TEXT_READ / FIGURE_VISUALLY_REVIEWED / COMPLETE_REVIEWED。
机器正文：MISSING / FULL_IMPORTED_UNVERIFIED / PREVIEW_IMPORTED_UNVERIFIED。
电子渠道：NOT_CONFIRMED_THIS_SEARCH / PAID_DRM_EBOOK_CONFIRMED；后续可增加确认的开放渠道，但必须填来源和授权范围。

一个公开序言可以是PERSONAL_STATEMENT＋EXCERPT＋LOCATED_TEXT_READ，同时对应书籍的机器正文仍为MISSING。三个轴并不互相排斥，也不能互相升级。
完整性由版权页/目录/末页及附页检查、文字和图示审校记录支持；不能根据文件大小、书名、字数或页数单独认定。

按项目保存法定条件和使用时间；按来源保存发表时间和读取时间；平台发行日与原书出版日分栏。重复转载不计作独立方法验证。
