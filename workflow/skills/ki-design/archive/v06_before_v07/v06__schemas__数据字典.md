# 数据字典与下一步建设

## 实体
- PERSON：姓名规范名，原文名，机构，公开职位，来源ID；一人多个同名别名需人工复核。
- ORG：正式名称，历史名称，起止时间，来源ID。
- WORK：项目规范名、官方标题、URL、设计/建成时间、状态、场址、阶段、七大主题、技术关键词、核实程度。
- CREDIT：项目ID + 人物ID + 原文角色词 + 来源ID（同项目多人保留独立行）。
- DOC：文献ID、作者原文、刊名/来源、发表日期、URL/ISBN、正文可用程度、版权标志。
- CLAIM：最小断言及其来源ID、证据类型A/B/C/D、冲突记录及审核状态。
- RULE：规则编号、适用场景、条件/例外/反例、证据ID、已验证案例集合。

## 重要非目标
- 本次只做公开内容蒸馏，不训练参数模型，不证明AI复现崔愷个人独有思考过程。
- 不能将团队成员仅仅视为署名名单：需按公开的主持/主创/专业角色、团队合作关系进行逐条核实。
