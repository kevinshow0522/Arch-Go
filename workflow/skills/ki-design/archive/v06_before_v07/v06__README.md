# 崔愷／崔恺与本土设计团队方法论 Skill · V0.6
可画空间生成与跨图一致性版｜2026-10-10

**真实结果：六册目标，确认一册的电子书销售渠道；零册完整正文导入，零册全文校阅。** 本包含公开资料研究摘要和来源，不含商业电子书全文，不是本人或团队授权产品。

## 直接使用
解压后保留 `cui-kai-local-design` 文件夹名，与SKILL.md的name一致。交给支持Agent Skills的宿主加载；普通对话可提供主文件及本次相关卡片。没有自动安装到任何用户软件，也没有训练新模型。

运行形态：新项目自然输入 → 已核作品与理念启发 → 可撤回假设及空间骨架 → 主案与实质不同备选 → 统一 geometry / adjacency / section 简报 → 平剖体量与构造表达 → 图像检查、代价和修正。

示例任务：
> 请用这个 Skill 为我的新项目做概念方案。资料不全的地方先作明确假设，给出主案和备选的空间骨架、平面组织、关键剖面与构造关系；如需图像，让各图属于同一方案。

## 主要文件
- SKILL.md：完整主指令。
- reports/电子资源核验与重构报告.md：六册检索结果、电子书入口和限制。
- references/books/：六册状态、渠道核验与检索日志、正文接入规范。
- references/reading/：历版公开证据与 V0.6 图纸阅读卡；references/theory/v06/：理念到生成判断。
- method/生成工作模式.md：由实证阅读转为新项目动作；图像生成与跨图一致性.md：几何底稿及看图纠错。
- method/operations.json、operations/：八张研究者操作卡，每张含输入、动作、输出、反例、检验。
- templates/：设计推演和授权询问信模板。
- scripts/：离线检索、受控导入、结构校验、样本测试、公开打包。
- evals/：证据门槛测试与待执行建筑师盲评。
- archive/：前版文件备份及原研究台账，只供追溯。

## 出版物与程序边界
电子书销售不等于可提取全文；DRM文件不解密。公开发布包不收私有语料。原始文字、照片、图纸、著作版权归各权利人，外部资料只以适量摘要与定位引用用于研究。
标准结构参考：https://agentskills.io/specification

## V0.5 更新边界
理论与条件案例进入设计必经路径；干预强度不再决定默认方案，空间和构造共同生成。V0.4脚本、原资料核验记录和二进制台账保持原样。六册书仍未取得完整正文；新文本演练不等同于建筑师盲评或建成项目验证。

## V0.6 更新边界
默认帮助生成新设计，不只评审。新增图纸/理论卡及来源范围，输出可画的平剖体量关系与主备方案，支持图像任务的几何简报和一致性核查。书籍全文状态不变，原脚本和二进制不变；真实执行的验收见 V0.6 报告，未执行的效果图或建筑师审查不算通过。
