# 崔愷／崔恺与本土设计团队方法论 Skill · V0.3（全文接入准备版）

生成日期：2026-10-10。**研究重构版，非崔愷院士本人授权或官方AI产品。**

## 为什么重构
V0.1聚焦个人和4个作品。V0.3（全文接入准备版）将“作者理论／历史工作室／团队研究／项目证据／研究推论”分层，补充七大主题与技术研究双轴，专门引入城市更新绿色策略、分类拆改、临时性与协作等方法。

## 本版真实覆盖
- 官网公开项目目录 **102 条标题**（其中有些仅为目录快照，不代表项目全集或全量详细资料）。
- **17 条独立项目页**建立来源链接及初步核验；其中 **12 项**写成结构化案例决策卡。
- **24 条**机构、项目、理论、出版资料来源；**16 条**有证据指向且附使用边界的候选规则。
- 没有获得《本土设计》全四册与《城市更新绿色指引》全文；不得称已通读这些著作。

## 关键入口
1. `SKILL.md` —— 可安装Skill主指令。
2. `references/theory/` —— 个人理论与团队方法分层。
3. `references/index/` —— 全部索引表（CSV和JSON），按真实源URL查询。
4. `references/cases/` —— 十二个从项目文字提炼、保留证据边界的案例卡。
5. `method/` —— 设计操作、16条候选规则与适用条件。
6. `templates/`、`evals/` —— 方案输出模板、反例测试。

## 使用建议
在支持Agent Skills的工具中将整个文件夹放到Skills目录，按需求调用`cui-kai-local-design`。如果只是ChatGPT对话，可直接粘贴主SKILL.md与当前适用的2—4张案例卡。

## 数据伦理与局限
- 保留原项目署名和多机构协同关系；不能因官网收录而假定崔愷个人主创。
- 本资料库为研究摘要与外部公开网页链接，不批量复制出版物全文或图片。
- 项目建设年份、施工过程、使用绩效需以各自独立来源补证；本研究采样时仅确认网页内容。
- 目录快照不可视为全量文献清单，后续要按时间、作者、主题开展系统补查。
