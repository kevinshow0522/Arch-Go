这是基于设计团队官网公开图像的原创视觉分析，不是现场调研、设计者意图的完整复原或施工图审查。全部 56 张官网图片已在缩略拼板上实际查看；其中平面、总图、剖面及若干关键照片逐张以原始像素查看。图号按官网 HTML 中图片第一次出现的顺序计数，去掉重复引用，不是出版物图号。网页没有页码。配套 [图像来源索引](../../index/sources_v06_drawings.json) 提供每一图精确 URL 与像素尺寸。官网未给照片摄影署名时，不猜测作者，也不将其当可自由再发布素材。本交付不附整套原图。

以下严格区分：
- O：本次图像可直接观察的形态、邻接与空间关系。
- T：官网文字说明；只做简短事实校准。
- I：从 O/T 推出的设计操作，是研究者综合，不冒称崔愷原话。
- U：目前不能确认，不能输入后续生成器为已知事实。

可读尺度：大多长边只有 670 像素，足够判断建筑/场地级的空间组织；不能验证房间名称、小字尺寸、节点做法、净宽、结构受力数值、规范符合性。不能凭图示比例尺去输出精确工程尺寸。局部材料看起来像木/钢/石，并不自动确定其真实构造。

## A. 苏州火车站站房：大跨度主空间与人尺度边缘并存

来源：本土设计研究中心（原崔愷工作室）官方项目页 https://cuikaistudio.cadg.com.cn/pro/180/ 。注意不是苏州南站（后者为筑境设计），也不是把车站景观或全部站城系统都归给单一建筑师。
署名边界：官网列合作建筑师王群、李维纳、王喆、龚坚、狄明、涂欣；合作设计中铁第四勘察设计院集团有限公司。官网记设计 2006、竣工 2013。需保留团队与合作设计署名。

实际读图：
- 图1，图中两幅均标“剖面图”，670×315，逐张查看。能读交通楼层叠置、局部下沉/地下部分、屋盖高低关系及大厅两端汇聚支承的形态；楼层标高、设备层与结构截面细字不可读。
- 图2，“总平面图”，670×481，逐张查看。实际上以屋顶轮廓与重复折面为主要信息，不能作为完整功能平面使用。可见十字展开的总体屋盖及主次屋顶尺度变化。
- 图7，深檐与汇聚形支承近景，670×436，逐张查看。连续菱形檐口下方是一段巨大的有顶户外空间；大屋盖旁还有更低的一层檐廊，行人尺度在两者之间出现。图9，候车大厅内景，670×444，逐张查看：高大连续空间没有被小院落分割，屋架/天花折线与透光面共同形成重复节奏。
- 图3、4、5、6、8、10、11、12于拼板实际查看：包括车道檐下空间、院落/门洞、远景等，不将这些缩略观察升级为细部构造读图。

O：剖面和大厅照片一起表明，最核心的使用空间仍保持大型连续体量。人尺度主要借低檐、庭院边缘、墙面、少数巨大支承及屋盖的重复小单元建立。菱形不只在外立面作图案，也在屋顶边缘、结构显现及天花节奏上出现。深檐把室内巨大空间向城市前场延长成有遮蔽的过渡带。
T：官网说明上进下出、南北入口，并以菱形系统处理大跨度建筑与苏州地域特征的关系。
I，因果链：不可割裂的大客流大厅 → 保留连续大跨 → 在边缘增加低尺度停留/集散界面 → 将一种几何秩序贯穿结构表达、采光与檐口，降低大型体量的陌生感。地域转译与工程组织可同时发生，不能把本土设计预设成碎片化小体量。

可迁移生成动作：
1. 先画“必须连续”的功能面积及人流方向；保持通行效率，不为风格插院。
2. 在连续主体外画“可停留边缘”：低檐、廊、绿地、下沉前场等作为候选，依据气候、集散与安检边界选择。
3. 提炼一种能同时参与屋盖分格、采光和尺度辨识的构造秩序，做三个变体比较。新方案不必用菱形。
4. 用到达剖面同时比较车辆、人行、出入口高差与遮蔽长度，避免只有正立面效果。

反向条件：大跨需求明确时，强拆为庭院群会损害功能；反之，小规模建筑没有必要模仿巨构汇聚柱或夸大檐口。地域符号与结构/排水/采光不相容时应改几何，不能为视觉相似强行复制。
U：本次没有可读各层功能平面、完整人流计算、详图与运行数据；不能宣称已验证换乘距离、舒适度、能耗或结构效率。金属色/木色外观不等于木结构。

## B. 北京德胜尚城：把高密度办公组织成可以穿行的街区

来源：https://cuikaistudio.cadg.com.cn/pro/124/ 。署名边界：官网列合作建筑师逄国伟、刘爱华、谢悦、吴斌；设计 2002、竣工 2005。不能把后来管理中的公共开放状况当作本次已验证事实。

实际读图：
- 图1，剖面拼图（网页无具体题名），670×135，逐张查看。可见多栋地上体量之间有空隙，下部存在连续地下空间；最右侧较低传统体量与主体形成对照。层数可看大概，净高与地下结构关系不可精读。
- 图2，首层组织图（本次描述名，原图题名不可读），336×548，逐张查看。长地块内一条斜向空带串联横向支路；各办公块的围合并不一致，一些院与街有狭窄连接，一些围合更完整。
- 图3，含德胜门箭楼的场地关系图，339×548，逐张查看。地块位于箭楼一侧；斜街方向与城市中重要历史目标建立联系，不能仅凭此图精确宣称每段街中心线都对准箭楼。
- 图18，台阶街道及传统构筑物对照照片，670×448，逐张查看。街并非完全水平；左侧现代墙身与右侧较低瓦顶体量夹出上升路径，台阶尽端仍能看见后方体量。无障碍替代路线不在此照片中，不能判断有无。
- 图4–17于拼板实际查看：跨街桥、街道天空切片、庭院古树、低瓦檐与矩形开窗并置可辨；原物/新建仿传统部分不可只凭照片分辨。

O：整体不是孤立主楼前摆装饰小院，而是公共空隙先形成连续网络，办公体量被它分开。地下连续、地上分块，意味着密度与步行渗透可分层处理。体量统一的直线边界与局部不同围合方式并存；桥和树在路径上制造上方收束与局部停顿。
T：官网明确七栋、斜街和各自庭院；地段有严格高度约束。
I，因果链：长条地块/历史环境/限高 + 办公密度 → 分块并共享地下层 → 斜向主街与支路连接各块 → 局部庭院提供识别与停留。这里“院”不是永恒原型，而是街区分配、办公组织和遗存关系共同产生的结果。

可迁移生成动作：
1. 先选两个或以上真实城市接点，画最有价值的穿行路径，而非先排七栋。
2. 将开发量拆成可独立使用/分期的单元，同时测试地下或底层共享服务的代价。
3. 以路径划块后，分别检验每块的办公进深、采光、入口识别和小气候，决定是否需要院、侧院或共享空隙。
4. 将历史目标和保留树木设为“关系约束”，允许转折、收放或避让；不要批量贴瓦顶。

反向条件：没有穿行需求、运营长期封闭，或高度与大进深生产需求不同的场地，照搬斜街+七院很可能牺牲功能而制造假公共空间。严寒强风区的狭长街巷还需风环境与冬季日照验证。
U：缺可读交通与节点详图；不能声称石材种类、桥结构、实际开放时段、地下全部为车库，也不能根据图18断言无障碍不合格。

## C. 湖南永顺县老司城遗址博物馆：用地形剖面分配显隐、采光与到达

来源：https://cuikaistudio.cadg.com.cn/pro/247/ 。这是博物馆，勿混同官网另页“老司城遗址游客服务中心”。署名边界：官网建筑设计崔愷、张男、朱巍、李喆；设计 2014、竣工 2015。

实际读图：
- 图1，剖面与立面拼图，670×474，逐张查看。看得到下部较长连续展陈层、上部局部抬起体量、屋顶绿化/树木示意和数处竖向开口。剖切位置未能可靠对应各平面。
- 图2，原题“博物馆一层平面图”，670×474，逐张查看。折线外轮廓围成较深的下层空间；左侧较大连续房间与右侧细分房间不同；中央偏下的入口/交通聚集位置可辨，但各室名称不可读，不给每室贴功能标签。
- 图3，原题“博物馆二层平面图”，兼场地关系，499×548，逐张查看。上部道路沿等高线弯曲，上层使用条带贴其下方展开，较宽下层转成外露平台/屋面与地形关系。不能凭小比例图独立判断防洪设计标准。
- 图12，下沉空间及上层石墙实景，670×447，逐张查看。外墙实面连续，天井内有大玻璃开口和水平遮蔽构件；建筑外观的少开窗与内部获得光线并不矛盾。
- 图4–11、13–14拼板查看：谷地远景、室内展厅、竖向窄院、眺望平台及突出的轻质坡顶入口。入口像一个明确的方向标，与大部石墙的隐入地形形成差异。

O：上下层的平面面积和轮廓不一致，不能把它画成两层同轮廓的“山地盒子”。下层较深空间与上层窄条带、屋面平台相互叠置。光通过局部下沉空间进入，外侧立面仍可以保持厚实。轻质入口与沉重墙面形成可辨的到达节点。
T：官网说明依西侧坡地、避洪选址、天井补充自然采光通风；石墙为与钢筋混凝土组合的墙体，不能误称纯承重干砌石。
I，因果链：坡道与谷地高差/展陈对封闭面的需求 → 剖面上藏入较深空间 → 为需要日光的部位切出院/天井 → 外立面可用少量定点开窗控制尺度 → 在真正入口集中表达轻结构与识别性。景观融合不是每一面隐形；入口刻意被看见也合理。

可迁移生成动作：
1. 先列道路标高、可安全建造区、展陈与辅助空间的采光差异，用三条场地剖面确定占地。
2. 对每种空间选择“埋入/外露/跨越/架空”，再生成体量，不先指定覆土低层。
3. 把采光口、院和通风路径落在需要它们的房间旁，验证进深与排水；不为俯瞰构图平均挖院。
4. 以入口、眺望和换层三处做空间强调，其他墙面节制，检查远景与行走视角是否仍易辨方向。

反向条件：地下水高、边坡不稳、遗址不得扰动、无法维护防水或缺自然高差时，不应复刻覆土嵌坡。对持续自然采光要求很高的办公/教学功能，不宜直接复制深埋厚实体量。
U：没有边坡、地勘、防水排水及墙身详图；自然通风/节能是设计者说明，非本次实测。植物是否长期保持、覆土厚度、入口构件真实材质不可确认。

## D. 西安大华1935：先判断保留对象，再分别加与减

来源：https://cuikaistudio.cadg.com.cn/pro/173/ 。署名边界：官网合作建筑师王可尧、张汝冰、Aurelien Chen（法国）、刘洋、高凡、曹洋、冯君；施工图配合西北建筑设计研究院、西部建筑抗震设计研究院、西安建筑科技大学土木工程学院。官网记设计 2011、竣工 2014，后续改造/运营不自动属于同一设计版本。

实际读图：
- 图1，总图/屋顶组织图（描述名），670×492，逐张查看。多个大厂房的重复屋面仍完整可辨，其间出现纵横可通行的空带；左下/下缘是尺度较小的既有建筑，整体没有被统一成同一种院落网格。图例与拆建边界标注不可读，不能逐栋计算保留率。
- 图5，保留柱梁及高侧光的大空间，670×457，逐张查看。粗糙旧柱与墙面、上层栏杆、钢构连接件以及高窗同时存在；没有构造资料，不能单凭外观判断每根钢构件新旧年代和具体加固作用。
- 图6，锯齿形旧屋顶墙段与大台阶公共空间，670×447，逐张查看。前方较高的新/改造屋盖与后方锯齿轮廓之间有明亮空隙；侧边台阶提供停坐方向，保留轮廓成为空间的背景而不只是一件孤立展品。
- 图2–4、7–12拼板查看：连续锯齿屋盖、小尺度旧房街道、可辨材料对比的入口/连接体、旧墙与玻璃界面并置。

O：项目容纳不同年代、尺度与屋面形式，不以同一种新风格抹平。去掉或打开部分空间后，原来的厂房柱网、锯齿轮廓可以转成公共空间的秩序。新介入常用于入口、垂直联系或连接，老材料并非只留立面；现有大空间也被利用。
T：团队说明区分早期砖木建筑的谨慎添加与后期大厂房的打开/减除。
I，因果链：不同遗存价值与空间能力 → 分级保留而非统一修旧如新 → 对小建筑补连接，对大厂房切入街道/公共节点 → 新旧差异承担导向与时间识别。可借鉴的是决策分叉，不是复制锯齿屋顶或锈钢皮。

可迁移生成动作：
1. 为既有建筑逐栋登记：历史价值、结构安全待核项、可容纳功能、尺度与对外接口。
2. 同场地产生两个不同介入区：“尽量不动主体、补服务”和“保留关键结构、打开局部空间”，禁止一刀切。
3. 把最少的拆除用于建立真实连续路径，保留柱/墙/屋面片段作为路径尺度与活动支点。
4. 新体量优先解决出口、设备、无障碍、连接等缺项，再考虑表达；用新旧接缝的可读性检验，而非以材料反差越大越好评分。

反向条件：结构不安全、污染未处理、遗产规定禁止拆改时，“积极减法”不是许可；全新场地没有既有结构，不应伪造工业残片。商业运营和消防不能成立时，空出漂亮街道并不等于成功更新。
U：未获得实测平面、剖面或拆改对照图；本例不能冒称完成剖面图细读。照片可读空间高低，不能替代受力、抗震和消防鉴定。没有客流/经营数据，不评价当下运营成功。

## 综合后可进入生成助手的判断，不应变成风格配方

1. 相似性应首先问“有没有把真实矛盾变成空间秩序”：苏州站保大跨、德胜引街区、老司城以剖面藏露、大华分对象加减；四例的操作并不相同。
2. 体量不是越低越碎越接近。先定义不能切开的空间，再定义可以穿透的边缘和节点。
3. 地域性至少跨两个层级工作，例如城市关系+路径、地形+剖面、结构表达+光线，而非仅选一种颜色或瓦屋面。
4. 生成每个关键动作时同时写反条件：若反条件成立，要允许方案完全不同。
5. 视觉校核至少成对：总图↔城市进入，平面↔主要路径，剖面↔采光/高差，构造表达↔近人照片。缺某一项就声明缺项，不能用氛围图自动补成事实。
6. 四例只能支持本次局部研究，不能代表全部生涯，也没有六本书全文阅读或建筑师盲评支撑。“气质接近”应作为可讨论目标，不作已认证结论。
