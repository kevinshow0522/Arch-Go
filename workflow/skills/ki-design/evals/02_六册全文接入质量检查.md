# 六册全文接入质量检查

在对用户声称“已纳入完整正文”前，须对BD01、BD02、BD03、BD04、GU01、GU02逐一检查：

- [ ] 取得用户有权使用的源文件并记录SHA256
- [ ] 校验文件真实性：书名、ISBN、版权页、版本
- [ ] PDF页/EPUB章节文本提取完整，无重大乱码
- [ ] 有大量图示或扫描页时逐页对照，未识别内容不能隐瞒
- [ ] 目录、前言、主体章节、附录/参考文献均被纳入，逐章节记录页码
- [ ] 项目署名、观点归属与团队/个人身份核对
- [ ] 生成索引、章节知识卡、更新R规则，并保留反例与例外
- [ ] 可检索原文定位；运行设计案例测试及引用回溯测试

六册任一文件未提供时，状态必须维持MISSING，不可标记完成。
