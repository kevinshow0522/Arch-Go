# 建筑设计专家库

这是用户的通用建筑资料库入口，不限定某个项目。知识通过来源文件、专题知识卡和续学记录保存，不能把建档视为已学习或现行依据。

## 资料位置

- 原始资料：用户授权的规范、图集目录。
- 专家库：用户配置的建筑设计专家库目录。
- 生成副本：仅使用用户指定的有效副本，保留版本与来源。

此公开包只含方法与入口，不含资料原文、知识卡、学习进度或任何项目文件。

先核实专家库入口存在；稳定目录不可访问时可读生成副本，并说明实际使用的版本。换电脑或路径失效时，根据用户提供的位置更新定位，不默认文件可访问。

## 按任务读取

先读专家库的 `专家库入口.md`。续学任务再读 `学习进度与续接.md` 及当前批次记录；设计问题先检索 `知识卡索引.md`，再从 `分类目录` 或 `资料分类总索引.json` 找相关原文。只加载当前主题，避免整库进入上下文。

资源用途分为规范标准、绘图表达深度、构造节点、规范图示解读、设计参考、产品专项资料、软件操作和待辨识；专业主题、版本及学习状态单独记录。目录和文件名分类须经封面、目录、总说明核读确认。

## 形成可复用知识

每批围绕一个问题阅读完整相关条款、图页、附注和适用条件。用 `知识卡字段.md` 保存问题、输入、判断／绘图方法、适用边界、来源版本与双页码、关联图、例外冲突、校核结果和下一步。知识状态对应具体页段与规则。

规范原文、图集、解读、产品资料和工程实例分别保留证据。技术参数用于设计前，核验项目所在地和建筑类型适用的官方现行来源，记录日期及替代关系。数字、单位、表格与脚注以原图页复核；冲突未解的规则保留待核状态。

绘图方法应给出所需输入、共同基准、落图顺序、平立剖及节点关联和校核项。材料与构造区分；图纸表达经验不替代专业系统参数。CAD／天正功能名称、当前对象操作、实际出图分别验证。

用户要求继续学习时，在文件中保存本批阅读范围、结论、未解决问题和下一批入口再报告进度。回答引用具体来源与适用条件，如实报告库的覆盖，不因技能已安装就宣称全库已学会。已有技能或项目约定相关时按用户当前要求配合使用。
