# Chinese tower reference scope

This public source package contains the modeling method and scripts. Nine historical case PNGs (the SKP embedded preview and eight diagrams derived from the source geometry) are omitted: their redistribution permission is not established by the software license. The source model is also not distributed.

The [image-modeling protocol](../chinese-tower-image-modeling.md) and [case metadata](../chinese-tower-case-evidence.json) preserve the historical methodological context. Image filenames and numeric observations are historical references, not evidence that those images were loaded in the current task.

Obtain authorized reference images or model data for actual modeling. If unavailable, explain the missing evidence and use only the general method; do not claim visual validation or silently substitute another building.
