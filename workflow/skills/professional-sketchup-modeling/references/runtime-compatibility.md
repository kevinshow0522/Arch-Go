# 运行能力与模式兼容

本机方法适配与 MCP/RBZ 程序构建分别判断。工具 schema 与实际返回决定可执行动作；文档不能增加程序能力，也不能授权模型写入。

## 建模开工与续接

- 实际建模首次激活或宿主模型变化时用 `sketchup_runtime(action=startup)`；该动作提供指导，不证明 SU 已启动、文档已绑定或写入成功。
- 首次连接、工具/软件升级或版本不明时读取 `capabilities`，按返回核桥接、读回、取图、保存、重开能力。已有有效结果可复用，不每一步重跑全部探测。
- 从实际连接核 SU 版本、目标实例、活动文档路径及当前状态；多实例或对象不明确时用 `instances/status/select_instance` 等实际入口。只读检查和模型写入授权分开；未保存文档不能为了检测路径而擅自保存或关闭。
- 续接先 `sketchup_project_status(project_id)`，核保存模式、原工作单元和下一动作；若文档或实例改变，按恢复入口重新核绑定，不直接把旧状态当现场。

2026-10-27只读能力返回：开发基线2019；2018为待目标验证的声明，2019仅历史试件记录；2024/2025适配标为 `planned_not_implemented`；本发行现场验收为 `not_run_for_this_release`。这是本次核对记录，不替代未来返回，也不代表本机正在使用哪个 SU 版本。目标版本未实现或未知时，先核有证据的可用路径；不可用则说明具体缺口，保留文件，不反复重试写入或宣称安装即兼容。

## 当前模式选择

新任务默认为 guided。0.5.39工具实现仍以原有首行口令选择新专家任务；单独传 `assistance_mode=autonomous` 会被拒绝并返回默认 guided。删除 Skill 中的品牌文字不会改变这个实现。

保留用户原始 `task_text`，不偷偷添加触发语句、伪造已有expert状态或修改签名。已有 expert/autonomous 项目按保存策略续接；新任务以 `begin` 的真实返回选择[引导路线](guided-operation.md)或[专家路线](expert-operation.md)。用户明确要求的模式无法满足时先说明限制，不能静默换模式；一般建模任务沿默认模式执行。

提供新的通用切换方式需要修改并验证 MCP 实现，本机 Skill 方法适配没有完成这一程序变更。无需让普通建模用户先选择或记住模式口令。

## 深度不等于工具阶段

概念体量、深化、局部修改、导出是任务用途，不能作为不存在的 `mode` 参数传入。创建受管任务时按来源选择现行 schema 的 `single_image / cad / freeform / refinement`，是否能编辑仍以对象范围和返回结果为准。

guided 保留固有计划；`omit_phases` 和 `repetition=none` 不删除其阶段。无适用构造时仅使用工具实际允许的核对/推进方式，不造假构件、空操作或审核通过。若无法在授权深度内结束，保留现有成果及检查点，指出程序限制，不把流程未闭合报成已交付。expert 也须遵守真实主形和适用样板检查。

## 局部修改、导出及范围

局部修改入口为 `sketchup_project_step(operation_intent=update, targets=[...])`，依[受管操作](scoped-operations.md)定位同一已有容器的目标及共享影响。`sketchup_project_patch` 不是已开放生产入口；整阶段重构才用 `revise_from`，不把它用于每个小修正。

普通导入 SKP、共享祖先定义和跨项目母型具有当前文档所列限制；不能仅把 `mode` 写成 `refinement` 就假定可任意编辑。先只读审计并核工具是否支持目标，已有可用且获授权的其他路径按相同源保护和读回要求执行；否则给出具体限制与可交回的修改依据。

纯导出任务先查现有模型/工具能力，不为截图新建受管几何项目。检验视图与正式分析图的投影、尺寸、透明背景、线稿等要求不同，按任务单与实际文件核对；不能宣称检验截图自动满足正式导出规格。设置机位、可见性或临时剖切后核原状态恢复；仅在用户要求保存这些设置时写入工作副本。

## 变更与恢复

修改绑定尺寸、来源或对象范围时先核当前schema与原任务；没有合法迁移入口不能手改状态。操作结果未知查原回执；几何已提交但证据失败只补证；真正回滚后才修正并重试，见[恢复入口](managed-recovery.md)。

离线检查、文件校验和能力查询不等于真机建模验收。对外分别说明工具可见、实例连接、读回/取图、保存重开、可编辑性和用户设计确认的实际验证范围。
