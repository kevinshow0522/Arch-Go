# 项目类型参考

按实际任务选择相关类型；可组合，不匹配时依据目标和证据组织，不强迫归类。类型参考不提供预设法规数值。

## 既有建筑改造

优先建立现状与图纸一致性、保留范围、使用中断/分期、专业鉴定接口和更新价值。将保留、拆改、替换对象分开管理并记录来源。现状不确定时可以提出调查和可比较策略，不虚构结构或设备结论。局部室内、入口和立面可各自作为子项，仍继承项目共享条件。

## 停车建筑

围绕车流与步行、坡道组织、停车效率、功能界面、结构与通风、充电与运营条件选择子项。所有效率比较注明面积和容量口径；可行尺寸、消防等要求按现行适用依据核对。几何推演、规范判断和运营假设分别保留来源。

## 文旅景区

围绕使用人群、季节和时段、游线、服务节点、文化景观资源、运营和实施约束组织工作。真实资源与虚构叙事分开；流量和经营情景必须标来源与假设。入口、游线、服务建筑、景观节点可跨阶段推进，不默认每个节点都做完整建筑设计。

项目特定风格、单次配色或甲方偏好仅留在对应项目，不自动成为公共方法。提出新增通用类型时记录适用边界和具体判断差异，避免堆积空泛分类。
