用于将崔愷与本土设计团队公开资料中的研究性判断，按当前问题用于建筑方案；依据用户提供的cui-kai-local-design V0.6包及本轮V0.7完善。V0.4八章、原有详细方法和表达规则保留。这里提供自含的核心方法；完整研究Skill未安装或暂不可读时，仍能依据本页推进明确假设的空间设计，依赖原文的引用保持待核。

## 何时使用

在现有路径与新容量、公共开放与安全管理、大空间与近人尺度、地形景观、新旧关系、空间构造或季节运营形成主要矛盾时读取。选一项主要机制及必要制约，不把全部机制叠加，不要求所有设计都采用某位建筑师的气质。已有明确方向或局部任务保持其范围。

## 条件如何进入空间

J01—J06对应研究Skill的六张理念卡；W01—W08是研究者操作，不是作者官方八步法。下列动作由项目条件决定，尺寸和形式为本项目设计选择。

| 当前矛盾与理念索引 | 可以比较的空间机制 | 关键图与推翻条件 |
| --- | --- | --- |
| J01：真实城市路径、停留与容量争地 | 先定连续空隙，再沿边放功能；比较旁路与局部跨越 | 总平和连续路径剖面标接点、入口与受控线；无通行权/使用需求时改为可控节点或旁路 |
| J02：消极邻界与室外活动需要 | 比较功能块偏移/局部旋转、正交错位、紧凑体量边缘切口 | 同容量平面核实际活动、进深、雨天路径与围护代价；室外收益不足时保留集中体量 |
| J03：公众穿行与会议/办公管理争地面 | 比较管控上移、侧向分流与局部架空 | 剖面同时标开放线、管理标高、支承与闭馆状态；气候、值守或垂直到达不支持时改为侧向分流 |
| J04：总体、结构与细部表达脱节 | 常规网格承担多数功能，少量关键关系贯穿体量、内部和节点 | 典型平剖与一个重点节点对照；非常规构件无空间收益或专业不支持时改用常规体系 |
| J05：绿色姿态与季节使用/维护冲突 | 比较季节分区、少量高价值室外节点与连续出挑；无种植时也应可用 | 剖面核热边界、遮阳、冬夏活动与维护；运营或性能不成立时缩减相关动作 |
| J06：景观/遗址角色与识别、容量冲突 | 比较显露集中、分合留视线与局部藏入 | 同尺度体量、远景和到达剖面对照占地、采光与基础；无高差或地下条件不利时取消覆土/埋入 |

有既有建筑时，另按W03逐栋/逐空间判断资源能力、结构待核、使用关系与分类干预；没有既有对象时跳过，不制造遗存。低层、院落、台地、地方材料和高层集中均为可能结果，不预定哪种更本土。

## 形成可以继续画的共同底稿

先交空间骨架，资料不足时列明确、可撤回的概念边界与容量。不能把假设用于暗改已给硬条件；每层可容纳面积、总量与目标明显冲突时先量化说明，并提出需改变的条件。

- **版本与几何**：方案ID/版本、北向、坐标/单位、楼层标高；给体量、公共空隙及主要路径固定ID，标数量、位置、轮廓、大致尺度及层数。
- **邻接与通行**：功能关系、公众/受控/后勤到达、门厅与管理线；核从入口到核心空间的连续性及闭馆状态。
- **关键剖面**：选真正经过主要矛盾的剖切线，标经过对象、地面/楼板/屋顶、主跨及支承、室内外与必要环境机制。
- **同版核查**：分别计算各层/功能与面积差额；将建筑、平台、院落、主要景观和路径完整轮廓纳入边界。概念红线可假设，内部仍须自洽；不只检查楼体。

采用了来源机制时，留一行“采用记录：本项目条件→J判断/W动作→已读来源卡/片段→本案决定”。只记录真正改变设计的部分，原创尺寸保持原创。需要图时实际绘制并看图，检查平面、剖面和体量对应；源几何变更先更新底稿，再同步受影响图纸及M07引用。气氛渲染、几何核查、工程确认分别记录。

## 来源范围与保存

完整研究包保留六张理念卡、四组V0.6读图、12张继承案例卡和102个项目标题；六册目标著作完整正文导入和全文校阅仍为零。公开材料研究日期为2026-10-10，本轮不把原卡的阅读记录升级为新核验。涉及书内观点、项目署名或具体作品事实时，按可访问的`cui-kai-local-design` Skill补读对应卡及source ID；不能以本页摘要替代原始证据。

四组机制来源定位：苏州站大跨与低尺度边缘（读图A，D06_180）；德胜尚城路径与分块（B，D06_124）；老司城遗址博物馆地形与上下层关系（C，D06_247）；大华1935不同遗存的加减（D，D06_173）。J卡来源包含本人访谈、署名文章及论文摘要，具体获取/阅读范围各不相同；它们启发本研究动作，不证明作者说过本页操作。

实际项目仍先定位项目并读有效条件，通过现有项目服务保存决定、成果、检查和续接点，参考[项目服务](project-service.md)。记录采用的J/W、卡片来源及项目图纸版本即可，不把通用研究原文或虚构测试题写成项目事实。既有项目不自动迁移已确认决定；后续遇到相关问题时明确采用新方法并检查影响。

案例不设固定研究或展示数量，按问题、资料等级与实际用途选择；局部研究沿用有效资料，资料包条目不自动计作项目研究完成。规范数值、专业性能、真实建造和外部发布按各自依据验证；文本演练与静态检查不替代实际设计验收。表达继续使用[既有规则](expression-interface.md)，不预选新的视觉风格。
