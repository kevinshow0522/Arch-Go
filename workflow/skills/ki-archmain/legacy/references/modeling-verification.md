# 可编辑建模与图模核验

> 本机执行入口（2026-10-27）：选用SU的已授权制作任务，按[建模章节接口](../../references/sketchup-modeling-entry.md)调用[professional-sketchup-modeling](../../../professional-sketchup-modeling/SKILL.md)。本页保留跨软件的通用核验要求，任务深度、编号与确认沿现行工作流。

方法版本：1.17｜2026-10-15。适用于05.5、05.7—05.9的空间推演及06.4—06.6的构造与模型修改；07引用核对后的视图，08管理最终文件。方法可用于不同建模软件，具体操作以当前可用工具为准。

## 先确定要用模型回答什么

从当前设计问题选择建模深度，例如院落能否连通、屋面如何界定主形、一个开口怎样接宿主，或只比较同一跨的材料。局部任务复用有效整体，不补建无关系统。模型用于空间判断时，应有可回查的平面、剖面或尺寸；图像意向和性能计算分别管理。

取得当前方案版本、来源图纸/图像、有效尺寸、允许变化及保留对象。CAD或用户确认布局作为控制依据时，先核图层、实体/块、轴向、锚点、洞口和保留/新增分类；模型细化沿用已确认平面，不自行移动、补造或省略原对象。照片只提供可见线索；未知高度、背面和隐蔽关系保持假设，不把透视像素当实测长度。

共同底稿记录设计对象、轮廓、主要空隙与路径、单位、坐标和标高。地理或CAD坐标进入局部模型时保留转换；构造参数、原生API和读回可能分别使用毫米、英寸或米，应在接口边界转换一次，并用实际跨度回查。

## 按形体和用途选择构造方式

| 当前问题 | 构造与检查重点 |
| --- | --- |
| 整体空间或建筑形态 | 主次体量、屋盖、退台及主要开敞共同表达；占位盒不能替代决定轮廓和空间的部分 |
| 截面或曲率变化 | 先确定控制断面、转折与边界，再选挤出、截面连接、网格或壳体；适用边界和厚度方向按工具核实 |
| 重复系统 | 先做真实宿主上的完整样板，核连接、尺度和边界，再用真实组件实例扩展；端部、转角、退台等例外独立处理 |
| 现有对象局部修改 | 明确目标实例、父容器、共享定义、变换及材质归属，分别确定只改一处还是同类一起改 |
| 同条件比较 | 固定底稿版本、容量口径、尺度和相机；只改变本次讨论的设计变量，记录收益和代价 |

完整主形先核宽高、层位、屋盖、连接和负空间，再增加分格与细节。轮廓沿进深不变时可挤出，截面变化时采用对应表示；曲面采样变密不能修复错误的控制点。实际共边处共享几何依据，出挑、退进和接缝保持各自设计关系。工具入口和参数依实际schema读取，不固定依赖某个生成器或另一Skill。

软件返回的构造阶段或工作单元用于组织当前操作，不替换八章和服务深度。普通任务按问题选择必要步骤；使用有固有流程的专业工具时遵守其实际计划、审核和许可，不伪造构件、证明或完成记录。

## 对象保护与真实执行

先核实际软件版本、实例、文档路径和修改前状态，留可恢复版本；ping只证明接口回应。对象审计还应检查出现路径、共享实例数量、局部与世界变换、隐藏/显示范围和用户手改。名称或包围盒只帮助定位，不能代替对象身份及作用范围。

只改一个实例时，先确认工具能隔离该实例内部变化；改共享定义时列清受影响实例。共享父定义内的嵌套对象尤其要核祖先作用域。工具只支持受管容器或暂不支持普通导入SKP时，先作只读审计；提供定位清楚的修改依据，或在已授权范围制作独立样板。新建重叠副本不能冒充原对象修复。

在允许对象和事务内执行，每次有意义的修改后读回关键几何及受保护对象。实际接触、洞口、朝向、层间连接和材质归属需对应检查；组件数量、材质名或模型包围盒通过不代表装配与建筑成立。

## 读回、看图与恢复

按问题选择整体、正交、剖切或近景；与来源或旧方案比较时保持可比尺度和视角，先核轮廓和空间，再核局部。记录实际看过的图与观察，未打开图不记视觉通过。补图只用于观察时，不重新执行已完成几何。

| 现场结果 | 下一动作 |
| --- | --- |
| 原操作结果未知 | 读取原操作身份、回执及当前模型，按工具恢复入口处理；不换新ID重复提交 |
| 几何已提交、截图或派生证据失败 | 保留已提交结果，补同次操作的证据与检查；不重放几何 |
| 明确失败且已回滚 | 根据错误修正脚本或参数，再按工具语义提交 |
| 程序重启或检查点恢复 | 核文件、对象与运行身份，沿原任务恢复；不把旧进程号或旧图当当前证据 |

离线测量检查验证所给数据；声明的依赖图只核记录和版本，不自动发现模型全部依赖。使用现场读回时核文件、对象、坐标系、单位及覆盖范围；有截断就缩小范围或补读，不能把传输完整当几何全覆盖。图模、面积、性能和专业确认分别取相称证据。

## 保存、变更与项目续接

跨CAD、模型和分析成果的任务交接及控制来源按[调用与衔接](workflow-coordination.md)，用[配套记录](../assets/design-change-record.md)引用同一对象、来源和未决事项。模型已符合有效目标时核对后沿用，不重复移动；专业返回与整次变更关闭分别判断。本文件的作用域、实际视图及保存恢复检查仍须执行。

任务工作文件、脚本和过程证据放项目working_directory，最终可编辑文件与必要图件核对后进入output_directory；项目资料沿用materials_directory。工具有默认输出目录时显式指定本任务目录。交付副本与受管源路径分别记录，复制后核文件和哈希，不移动或手改工具维护的运行签名与状态。

保存后重开或作与任务相称的独立读回，核对象、尺度、材质及资源。文件存在、可打开、可编辑、视觉检查与专业确认各有范围；尚未执行的检查保持未验证。

在本工作流原任务中留一份简要关联：方案版本与来源；建模任务/工作单元和原操作入口；设计对象与当前模型路径；有效文件与检查；未决事项和下一动作。工具的project_id与本工作流项目/任务ID分别保存，不因同名互换，也不为每个构造阶段建立业务项目。

建模工具结束后，先判断本次设计目标是否满足，再保存成果、核文件并更新任务状态；一个模型单元完成不自动完成章节或项目。修改设计事实后检查受影响平剖、指标、专业接口、材料费用及07引用；纯表现调整按相称范围复查。跨工具自动同步和依赖发现只有实测后才可登记为已实现。

## 局部任务示例

“只调整西立面一跨材料，其余保留”：读取同版底稿及授权范围→查目标实例和共享关系→比较材料是否影响厚度、洞口或连接→执行允许的定向修改→同视角看图并读回目标与保留对象→保存核对→在06.4/06.6留成果与差异，必要比较归05.9，07仅选择展示，08登记实际文件与交付。资料不足时先交范围明确的修改依据，不重新开展全项目研究。
