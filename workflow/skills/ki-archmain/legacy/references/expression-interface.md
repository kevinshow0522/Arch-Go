# 分析图与交互表达方法

方法版本：1.15｜表达规则1.2｜2026-10-15。

用户体验03.1样稿后确认“很不错，就用这种方式”，随后补充“分析图的样式这样也是可以的”。据此采用以下图面风格与阅读方式。03.1为首个已确认样板；其他章节按设计问题迁移，不将确认视为所有章节表达已经完成。

用户随后明确底图与分析分层、分析图使用动画，并优先采用世界地图底板。首版图片样稿继续作为已确认风格与阅读方式的依据；后续地图样稿的功能检查、图面反馈和用户认可分别判断。世界底板分层动画v0.2的分析图质量收到用户否定反馈，不能作为成熟图面范例；后续片区矢量叙事演示v0.1已做独立检查，图面仍待用户反馈。当前实现与确认状态见文末。

## 从专题判断到图面的制作路径

常用路径为可靠资料整理与配准→建筑专题判断→可编辑静态主图→同源分层叙事动画→图文与结果帧。已有合格图面时复用其数据与对象，局部修订只重查受影响部分。

1. **整理依据与覆盖范围。**核对来源、日期、坐标、方向、单位及可用精度，保留对象标识和缺失范围。道路、轨道、水体、建筑和边界按可靠资料辨认；显示分类与法定等级分开。缺失几何或未调查部分明确留缺，不为图面完整补造。
2. **确定专题与可支持的判断。**每图说明要回答的设计问题、有关条件、空间关系、可得结论及待核事项。专题小图各自解释有区别的问题，并与主图对应。资料只能支持现状关系时就表达现状关系，不为填满图面制造结论。
3. **先完成静态主图。**使用可编辑SVG或相称的矢量源文件组织底图、现状、分析和标注，安排主次、线重、取景、图例及必要方向和尺度说明。用实际阅读尺寸检查空间关系是否清楚，再为有解释价值的关系增加动画；展示精度服从依据精度。
4. **按判断过程编排动画。**可沿背景条件、关系展开、综合阅读组织停点，具体段数随内容确定。每个停点都能读到当前关系、对应说明和证据；单纯依次出现图形不等于完成分析。图面修订回到同一套对象与样式，再更新动画和静态输出。

需要地理整理时可选QGIS等工具，矢量图面可按需用Illustrator精修，SVG可作为可编辑图层；D3投影与GSAP时间线已用于独立演示。按真实输入和当前连接选择工具，不要求每次走完整软件链。QGIS、Illustrator、MapLibre完整本机链尚未验证；地图引擎及世界轮廓不自带全球详细数据，所用服务、覆盖范围与实际连接另行核实。

公开站点位置仅支持位置关系。步行可达性判断还需核对站点出口、场地入口、实际路径、通行条件及相关高差；直连线不替代路径，距离圈须说明距离口径，任意半径不作为步行时间或服务范围的验证。资料不足时先完成有依据的专题，并明确待核内容。

## 图面与布局

以大幅主图组织阅读，底图采用浅色、灰度或低饱和环境信息；少量暖色突出当前研究对象、关键联系或重点。保持线条层级、图例、编号和标注清楚，色彩同时配合文字或线型。界面随浅深色适配，原始参考或项目图片保持其自身色彩，图面可读性优先。

桌面默认主图在中央或左侧，关键说明与对应局部在右侧；专题与视图范围切换紧邻主图。辅助信息按需展开，窄屏改为主图、关键说明、对应证据的纵向阅读。沿用试稿的平整界面、细分隔线和克制的强调，动画用于说明分析关系及过程，纹理与重复信息不占用主要图面。

这些是当前选定的常用方式，图件比例、说明位置与辅助视图数量可按对象调整。需要纯图纸时，仍可用同样的图面语言输出独立可读的静态图。

## 世界地图底板与独立图层

未来地图类表达优先采用可连续缩放、移动和定位的世界地图底板，组织世界、国家或区域、城市、片区与场地的定位关系；项目阅读入口可直接落在适当尺度，不要求每次播放完整全球定位过程。具体底图来源、地图样式与承载工具按实际能力选择并验证，不指定尚未测试的服务。

底图与分析分别维护，保持一致的坐标、范围、方向与当前视图，记录来源、日期和精度。世界底板提供定位与地理背景；边界、尺寸、高程等场地深化衔接可靠测绘、现状图、当地详细地图或高程资料，底图可放大不代表精度提高。其他局部底图须核对配准；没有可靠配准的照片、平剖或扫描图作为关联视图，标明位置和阅读方向，不假装精准叠合。

| 图层 | 内容与作用 |
| --- | --- |
| 地理底板 | 地图或影像背景，承载连续定位与空间参照；色调按已确认风格弱化 |
| 现状对象 | 有来源的场地边界、建筑、道路、地形与资源等，按项目选择 |
| 分析要素 | 联系线、范围、方向、专题结果或关系图形等，独立显示、选择及控制动画 |
| 注释与联动 | 对象编号、图例、文字、照片或断面，跟随当前分析与视图状态 |

05／06的拟议策略或方案另设独立图层，与03现状及分析区分状态。图层清单按实际问题设置，不强制每个项目具备全部数据；纯关系图、平剖面及节点分析也采用依据图形与分析要素分开的方式，不强制套用世界地图。

## 分析动画

交互版分析图默认以动画组织表达，在静态图面与判断核对后制作。根据问题让关系线逐步建立、范围或要素依次呈现、路径沿方向展开，或随真实时序和方案状态切换；一段动画说明一个可理解的判断过程，文字与图例同步当前对象或步骤。地图移动缩放时分析对象保持配准，尺度切换保留当前选中对象及相称说明。

提供播放、暂停、重播及步骤或关键帧查看，用户可停留阅读，遵循宿主减少动态效果的设置。暂停、结束或静态模式仍保留重要结果。动画速度是阅读节奏；只有有模型、输入、计算或实测支撑时，才对应真实时间、流量、日照等性能变化。区分逐步讲解、假设情景和实际结果，演示性路径及显现次序不冒称模拟。

图文及其他静态输出从相同图层、视图与数据提取结果帧或必要序列，保留图例和说明。两类阅读共享专题、步骤或关键帧、来源版本及聚焦；选入展示时保存动画段、停点或结果帧及必要图层状态。不会播放的输出仍应独立成立。

## 图、文字与局部联动

每张主图先明确要回答的设计问题，再绑定实际对象、必要图注和来源。点选图中编号、空间或专题，可以查看对应说明、照片、断面或原图局部；点选说明可反向定位到图中。热点必须落在有依据的位置，局部可以回到完整来源确认关系。

尺度与专题根据实际资料设置。只有属于同一场地且来源关系明确的视图，才能组织区域、周边和基地的连续定位。不同案例或参考分别标识；不将不同地图拼成一个项目，不将参考图中的地名、数字、专题数量或图例复制为项目事实。

只有图片时，先实现原图显示、放大、局部、点位及图像对照。真正的图层显隐、模型剖切、面积计算和参数推演分别依赖可分层图形、模型或可复算数据；图像局部切换不称为已分离图层或新的分析结果。

## 同源图文阅读与成果选择

交互阅读与图文阅读共用成果对象、原图或模型、说明及来源版本。切换时保留当前视图范围、聚焦对象或专题及其对应局部，图文版可以在连续阅读中补充必要关系说明。重要结论在静态输出中完整可读，不只藏在点击或悬停中。

需要选入展示时，保留成果标识、来源版本、视图范围、对象或专题、缩放或视点，以及必要图层、动画段／停点、展示类型与图注；再次查看能恢复有意义的阅读状态。只选实际成果，未选内容保留。源成果更新时检查关联位置，保留历史交付和用户手工编辑。

涉及设计变化时按[调用与衔接](workflow-coordination.md)记录输入、控制来源及受影响图件；候选分析可先支撑设计判断，最终表达引用有效控制版，并返回可编辑源、结论依据及实际检查。图面中的简化或修改不自动改变设计事实。

界面试选、浏览或参数试算不自动改变设计决定、任务完成或项目正式清单。实际保存、项目登记和发布按相应能力及授权分别执行、核验，不能以聊天样稿状态代替项目持久记录。

## 章节迁移与检查

03.1优先采用多尺度定位、场地与周边关系主图、专题及点位对应说明。03其他子项按气候、现状、交通、高程、景观或市政问题选择相称图件。05方案对照可复用主图阅读与同条件切换，06平剖节点可复用对象联读，01／02／04按各自证据组织；迁移时不强制每项设置地图、三维或交互。

检查时分别记录以下结果，不以控件或脚本检查代替图面阅读：

| 检查对象 | 完成依据 |
| --- | --- |
| 分析与图面 | 当前问题、条件和空间关系可定位；主次与线重清楚，专题各有作用，重点颜色不混淆现状与拟议动作；图例、文字与实际对象一致。查看实际尺寸的静态结果帧，按已有确认风格复核。 |
| 地理与图层 | 底图、对象、分析、标注在缩放移动时保持配准；核对投影、闭合面与孔洞方向、缺失边界及显示分类，避免错误填色或裁切误导判断；图层独立，缺失资料已说明。 |
| 动画与联读 | 播放、暂停、重播、停点和减少动态效果可用；专题取景对应内容，文字及图例跟随；恢复时同步视图、对象、图层和动画停点，结束残留过渡；图文与交互共用来源、版本及聚焦。 |
| 输出与打开 | 检查可编辑源文件及同源静态输出；桌面、窄屏和实际采用的浅深色均可读，标签无关键遮挡。独立浏览器预览与目标宿主内联打开分别验证，记录真实可用入口。 |

只登记实际运行与检查结果。图面复核、功能检查、用户确认、真实场地或专业分析验收及正式工作台集成分别记录。
