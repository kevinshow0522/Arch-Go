# SketchUp 建模：工作流调用入口

本机接口，2026-10-27。使用 SketchUp 制作、修改或导出模型的已授权任务，调用 [professional-sketchup-modeling](../../professional-sketchup-modeling/SKILL.md)。独立建模也可直接调用；已经选择 Rhino 等软件的任务沿原软件执行，不强制转换。

主流程管理项目、工作包、分工和确认，章节 Skill 组织本轮成果，KI-design 提供空间判断，建模 Skill 执行几何并返回检查。Skill 可被发现不等于当前 SU 已连接；建模程序兼容性与真实设计验收分别判断。

## 哪些任务调用

| 入口 | 触发与输出 |
| --- | --- |
| 03 场地研究 | 需要三维地形、周边体量或场地关系验证，且本包选用SU时调用；交回可编辑场地模型及核对视图。不因取得地图资料就声称模型已完成，也不提前确定05方向 |
| 05 W5.2 总平与体量推演 | 本包选择SU且建模任务单已讨论/授权时，明确调用本 Skill；按方向与步骤制作体量、必要剖切、顶视和分析机位导出 |
| 05 W5.3/W5.4 | 功能、流线、立面或重点空间需要几何验证时续用同方向模型；局部修改不重启整套方案 |
| 06 W6.3 / 06.6 | SU模型深化与图模协同的直接入口；06.1—06.5的具体几何修改按需调用，交回修改范围、保留对象检查与图模差异 |
| 07 | 调用现有SU模型的导出与一致性核对；分析图/提示词接收实际同版底图。需改设计几何时返回对应05/06任务，不借展示重定方案 |
| 08 | 按交付清单核实际SKP、图件、资源、版本和可编辑范围；不自动新建模型或重复已完成检查 |

01、02、04及纯文字讨论不默认建模。只有具体任务明确需要模型时才制作；章末包仍只汇总已存成果，缺图模返回对应制作任务，不在章末临时重建。

## 调用与返回

1. 从现有工作包、步骤卡和建模任务单提取用途与深度、C/P和方向/步骤、主线/指标/底稿版本、控制来源、单位原点/北向/标高、可变及保留对象、授权目录、所需图件。已有资料与授权沿用，不要求用户重填表或重复确认。
2. 按[建模工作流交接约定](../../professional-sketchup-modeling/references/workflow-integration.md)执行，先核当前工具、文档与作用域。具体调用参数以工具schema为准，本页不创建额外MCP字段。
3. 工作流项目/任务ID与工具受管project_id分别关联；工作单元和构造阶段不替代章节或设计步骤。建模按现有分工由GPT执行，任务执行者须实际填写，不假设服务已自动分配。调用 Skill 不自动发送消息、另开聊天或越过工作包确认。
4. 返回同版SKP、必要导出图及其方向/步骤/机位、实际文件路径、检查范围、推断/缺口、用户确认状态及下一动作。过程和签名状态留工作目录，交付副本按绑定项目目录核对后登记。
5. 几何检查、用户设计确认、保存重开及正式交付分别记录；工具 `review/finished` 不自动确认设计或完成工作包。变更影响的平剖立面、指标及07引用进入待复核，核对或重导后再更新。

详细构造与运行限制留在建模 Skill；通用核验沿[已有建模核验](../legacy/references/modeling-verification.md)。本页只负责路由和交接，不维护第二套指标、模型或业务项目库。

## 同步范围

`local-skill-adapters.json`中的 `sketchup-modeling` 接口与KI-design接口独立标记，可以同时附加到同一章节。正本SHA或锚点变化时先停止合并并复核。建模Skill全包由 `professional-sketchup-modeling/LOCAL-PACKAGE.json` 与 `LOCAL-SHA256SUMS.txt`校验，源包在工作区skills，安装版在本机Codex skills；未列入清单的用户附加文件保留。

以上是本机方法部署，不代表已同步其他宿主、已修改MCP程序或已完成真实项目验收。工作台继续只读，不新增界面入口。
