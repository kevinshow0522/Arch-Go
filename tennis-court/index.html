通州16片网球训练中心策划

选址参考点：北京市通州区潞邑街道孙各庄片区，通运路附近（WGS84 116.6973352E, 39.9277580N）。本项目为策划阶段，无用地红线，以下布局按假定的规整矩形用地编制。

用地 25亩（156.40×106.57m，约16,668㎡） 16片标准网球场，全部室外硬地 东西两区，每区8片（4×2） 两排场地之间4m休息走廊，东西贯通 中部装配式模块用房 单层约594㎡ 南侧两排停车 92个小车位 长轴南北向

结论：按业主批注，项目定为16片全室外硬地，不做气膜；两排场地之间加4m休息走廊，中部配套改为可整体搬迁的装配式模块用房，停车改为两排。基准情景（弹性丙烯酸、中值造价、利用率55%、租金5万元/亩/年）下，总投资约—万元，年收入约—万元，年成本约—万元，EBITDA约—万元/年，静态回收期约—年。全室外方案冬季（12–2月）约3个月基本停业，盈利对租金和利用率高度敏感：保守情景（利用率40%）EBITDA约—万元，乐观情景（70%）约—万元；在5万元租金下盈亏平衡利用率约—%，在55%利用率下盈亏平衡租金约—万元/亩/年。按基准假设，这个项目接近只够保本，决策前应先把租金谈下来，并同时落实提价、提高教学占比、会员储值和冬季降本，连同租金谈判6项合计可把EBITDA提高到约—万元/年（回收期约—年，见04节“改善收益的抓手”）。

01总平面布局

东西两区各8片场地，每区东西向4片并列、南北向2排。两排各自保留端线围网，两道围网之间是4.0m宽的休息走廊（装配式轻钢廊架，带遮阳顶棚、座椅和直饮水点）。走廊向中部配套带开口，并穿过中部配套带，把东西两区连成一条150.4m长、贯通全场的走廊。中部24m配套带布置4m消防车道、北端消防回车场、内庭绿地和装配式模块用房。南侧26.43m进深依次为：场前步道2.0m、两排垂直停车夹一条6m通道（5.5+6+5.5=17.0m）、7.43m的南侧绿化与入口缓冲；通道东西两端向南接城市道路作为车行出入口，正中是入口广场和人行通道。

布局复核与说明

  • 区宽：4×10.97 + 3×4.00 + 2×3.66 = 63.20m；区长：36.57 + 4.00 + 36.57 = 77.14m。每排端线外各留6.40m缓冲，再加4.0m走廊，相邻两排端线间距16.80m。
  • 总宽：3.0 + 63.20 + 24.00 + 63.20 + 3.0 = 156.40m（不变）；总长：16,667÷156.4 ≈ 106.57m = 北侧绿带3.0 + 场地区77.14 + 南侧26.43。南侧26.43m = 场前步道2.0 + 停车5.5 + 通道6.0 + 停车5.5 + 南侧绿化与入口缓冲7.43。
  • 休息走廊：走廊位于两道端线围网之间，每片场在走廊侧的围网上开门（位于场间空档处，不在端线正后方）。走廊向中部配套带开口，北接内庭绿地、南接模块用房北侧的休息补给间，运动间隙可直接取水、购物、休息。穿过4m消防车道的一段，顶棚净高按≥4.5m设置，不影响消防车通行。
  • 模块用房：33个6×3m模块拼成18×33m单层用房，取消门厅和观赛席。功能自北向南：休息补给（饮水、售货，面向走廊）108㎡；男更衣淋浴72㎡、卫生间72㎡、女更衣淋浴72㎡；器材·穿线·零售72㎡、教练办公36㎡；配电与设备间54㎡、储物值班36㎡、服务前台72㎡（小型前台，面向入口广场，不设门厅）。模块采用预制墩式基础，可拆装、整体移动，用地到期后可搬迁再利用。
  • 车位核算：车位按2.5×5.5m、无障碍位3.7×5.5m。北排西段1个无障碍位 + 23个标准位，东段同样，计48个；北排两端各留2.0m绿岛。南排因东西两端各让出6m出入口道路，西段、东段各22个，计44个，其中东段最东9个为充电车位。合计92个，比修改前78个小车位多14个，因为取消了环形车道和2个大巴位。
  • 消防：消防车经东西两端出入口进入6m停车通道（兼消防车道），在正中接4m中部消防车道向北直达场地北端，北端设24×15m回车场（兼休闲广场）。尽头式消防车道长约78m，按GB 50016设回车场（≥12×12m，大型消防车≥18×18m，需复核）；两端出入口转弯半径需按消防车型复核。
  • 绿地率：本方案绿化约14.5%，比修改前（11.5%）有所提高，但仍明显低于北京多数地块控规要求的绿地率（常见20%–35%）。如果控规要求较高，可采用植草砖车位（部分地区可按一定比例计入）、把北侧3m带加宽，或减少车位。这一项必须拿到控规指标后复核，见第03节。
  • 朝向：所有场地长轴南北向，符合JGJ 31-2003第4.2.7条。地块如需旋转，可北偏西不超过10°、北偏东不超过5°。冬春季西北风强，北侧和西侧外围网挂30%–50%透风率的挡风布；走廊顶棚做东西向通长，对场地内的风也有一定的遮挡作用。

02前提与选址条件

区位（仅作参考）

参考点位于潞邑街道孙各庄片区，紧邻南北向的城市次干路通运路。东侧约200–400m是已入地的东六环（2025年4月隧道通车，地面改为六环高线公园）。东南约1.2km是副中心行政办公区北缘和潞城中心公园。周边主要是孙各庄棚改安置房、含章园等新建居住区。

  • 生源：1.5km内有北京五中通州校区（约450m）、北京第一实验学校、龙旺庄学校、北京小学通州分校，适合做青少年培训和校企场地共享。
  • 竞品：潞邑、潞城方向几乎没有直接对标的商业网球场。最近的室内竞品是通州首家气膜运动馆（3片网球场，2025年12月开业），冬季客源会流向这类室内场；城市绿心有6片室外场。
  • 坐标：国内地图使用GCJ-02/BD-09坐标，同一点在国内地图上大约要往东偏0.006°、往北偏0.0013°，核对点位时要先换算。
  • 东六环隧道：场地如果靠近隧道，打桩、开挖、堆载（包括灯杆基础和模块用房基础）需要满足隧道保护区要求，需向首发集团或市交通委核实。

规划注意事项

  • 用地性质：长期经营的网球场应落在体育用地（A4），或依规在公园绿地、公共服务设施用地、居住用地中兼容布置（《北京市体育设施专项规划（2018—2035年）》）。在绿地中建设应以室外、低硬化为主；本方案全部为室外场，配套为可拆装的模块用房，与这一要求较为契合。
  • 临时用地：孙各庄属潞城棚改片区，周边可能有储备地块。临时使用协议的期限常见3–5年（经验估计），本方案的模块用房、轻钢廊架和灯杆都可拆装，到期可整体搬迁。
  • 副中心控规：需查地块所在街区的用地性质、容积率、绿地率和限高。本方案建筑为单层模块用房（高约3–4m）和开敞廊架，高度不构成制约；地块距行政办公区约1km，夜场照明和外观可能仍需专项审查。
  • 审批：只建室外场时，一般走园林、城管或街道备案。装配式模块用房可能按临时建筑办理（有期限限制），也可能要求办理建设工程规划许可和施工许可，各区口径不一，需与区规划自然资源分局确认；廊架是否计入建筑面积和建筑密度同样需确认。
  • 邻避：周边以住宅、学校为主，建议22:00闭场，灯具采用截光型、防眩光产品；夜场击球声对北侧住宅的影响需评估。
  • 公益属性：在政府或国有土地上建设时，可能被要求保留公益开放时段或惠民价格，这会压低收入（测算未计入）。

控规指标容积率、建筑密度、绿地率、限高绿地率要求若≥20%，需压缩停车或改植草砖，车位可能降到约60–70个；建筑密度口径若计入廊架投影，约7.2%。

冬季运营安排12–2月停业、减员值守，还是安排其他活动业主已确定不做气膜。冬季停业时可减员降本（见04节“改善收益的抓手”），也可利用模块用房开冬季体能课，测算未计这部分收入。
目标客群与培训定位大众订场、青少年培训、赛事承办的侧重；是否与学校或体校合作教学时段占比（测算取已售场时的40%）、私教单价和训练营期数是收入的最大变量。
投资上限与收益目标资金上限；目标回收期或IRR基准情景回收期很长，需明确可接受的回收期，再决定是否压缩造价（面层、灯光、走廊档次）或分期建设（如先建8片）。
运营模式自营、委托运营或出租给俱乐部出租模式下收入变为固定租金，人员成本和教练分成不再计入；自营的回报更高，风险也更大。
市政水电接入容量距电源点距离、可申请容量全室外方案以场地照明为主，约400kVA，测算已按40–90万元计入电力接入与箱变。
消防与交通开口可开口的城市道路及位置；消防车道和回车场要求本图假设南侧临路，停车通道东西两端各开一个车行口。如只能在东侧或西侧开口，停车和入口广场需整体翻转。
复合业态是否需要中心场、匹克球、儿童区业主已明确不设观赛席。中心场需加宽到约40×20m，会占去1–2片场地或部分停车；匹克球可在错峰时段于网球场上划线兼用，不影响布局。
地块现状地形测绘、地勘、地下管线、拆迁或回填情况回填土需换填或加厚基层，场地单方造价可能上浮20%–40%；预备费已按8%计。

默认参数：弹性丙烯酸，中值造价；闲时80元、黄金时段120元，夜场灯光费20元；租金5万元/亩/年；私教400元/小时、场馆分成40%；教学时段占已售场时40%；综合折扣8%，40%场租走平台；冬季不减员。保守/基准/乐观的利用率分别为40%/55%/70%，训练营基数分别为25/40/55期（全室外只有暑期营，按基数×0.7计）。

敏感性一：租金 × 利用率的EBITDA（万元/年）

只改变租金和利用率，其余参数跟随上方计算器。括号内为静态回收期。

敏感性二：盈亏平衡所需的租金或利用率

盈亏平衡指EBITDA为0；“10年回本”指稳定期EBITDA达到总投资的1/10。其余参数跟随上方计算器。按全场25.00亩计，租金每增加1万元/亩/年，年成本增加约25万元。

改善收益的抓手

以基准情景默认参数为起点，每一项单独调整，用同一套公式计算对EBITDA的影响；最后两行为组合效果。提价一项假设利用率不变，实际可能有流失，结果偏乐观。

  • 会员储值对EBITDA的直接影响不大，主要价值在于提前回笼现金（预收款不计入EBITDA）和锁定冬季前后的客源；储值预收资金需按预付卡相关规定管理。
  • 教学占比是单项影响最大的经营抓手之一，但受教练供给和35%上限约束，需要提前签约教练团队、与周边学校建立合作。
  • 冬季停业降本需要用季节性用工或劳务外包落实，核心岗位（管理、教学主管、财务、安保）不减。
读数提示：全室外方案冬季（12–2月）约3个月基本停业，全年只有约240个可订日，收入天花板较低；场地租金是最大的单项固定成本之一，在55%利用率下，租金每变化1万元/亩/年，EBITDA反向变化约25万元。模型假设每片场的利用率与场地总数无关，16片室外场在潞邑这样仍处于入住爬坡期的片区能否卖到55%，是最大的不确定因素，建议在签租约前通过周边学校、企业和俱乐部取得意向订场量。模块用房和廊架的搬迁残值未计入现金流，见05节。

05关键假设与数据来源

运营假设

  • 营业：全年平均每片每天15个可售小时；室外可订240天经验估计，12–2月基本停业。
  • 黄金时段占已售场时的65%；会员储值、平台团购等的综合折扣按8%计经验估计。已售场时中约30%需开灯，加收灯光费。
  • 定价：闲时80元、黄金时段120元、灯光费20元研究推荐值，参照朝阳体育中心室外90/130元。
  • 教学：教学时段占已售场时的40%（基准下约为总可售场时的22%，上限35%）。其中一半为私教（400元/小时，场馆分成40%），一半为青少年小班（按5人×80元/人·小时，教练成本40%）经验估计。
  • 训练营：每期12人，人均2,000元（半日营和全日营混合），教练成本45%。全室外只办暑期营，按期数基数×0.7计经验估计。
  • 其他收入（零售、穿线、饮品、团建赛事、广告）按场租与培训收入的10%计，毛利率40%经验估计。
  • 人员（北京，含单位社保公积金）：总经理1人31万元、运营/市场2人共31.6万元、教学主管1人23.8万元、前台客服6人共63.6万元、场地维护与保洁6人共56.4万元、安保2人共18.8万元、财务行政1人12.7万元，共19人。社保按2026年度缴费基数下限7,270元计。
  • 能耗：LED照明每片约4kW，全年约1,000个开灯小时，电价约1.3元/kWh（夜间高峰）。配套用房及室外水电约20万元/年（沿用修改前口径，模块用房面积减半，实际可能略低）。
  • 面层维护：丙烯酸每5年重涂（约45元/㎡），另加日常每片0.3万元/年。
  • 其他：保险1万元+工程费的0.2%；营销为收入的4%；平台佣金按40%场租走平台、费率7%，另加订场系统2万元；物业、环卫、绿化养护10万元；耗材每片0.6万元；设施日常维修为工程费的0.5%；税金及附加按收入的3%简化计算。不计所得税、折旧和融资成本。
  • 场地租金：默认5万元/亩/年（约75元/㎡/年），按25.00亩计约125万元/年。研究给出的基准值为7.3万元/亩/年，政策性用地可低至象征性水平。

投资假设

  • 场地构造：级配碎石15–20cm + 水泥稳定碎石15–20cm + 沥青混凝土5–6cm + 面层；按16片围网内全面积9,245㎡铺装（含场间空档）。
  • 单价取研究给出的低/中/高三档；面层：硬地丙烯酸40/50/65元/㎡，弹性丙烯酸75/90/120元/㎡，硅PU 100/115/150元/㎡厂商报价。
  • 外围网4.0m按798.2m计（场间端线围网由1道变2道），排水沟沿两排围网四周同长计。灯光拆为灯杆（64根，4,000/6,000/9,000元/根）和灯具、电缆、配电（每片21,000/35,000/60,000元）两项，在54根灯杆时与修改前每片3.5/5.5/9万元的口径基本一致经验估计。
  • 休息走廊：装配式轻钢廊架602㎡，800/1,000/1,300元/㎡，含遮阳顶棚、地坪、座椅和直饮水点经验估计。
  • 配套用房：装配式模块用房（精装集装箱房，单层）594㎡，800/1,100/1,500元/㎡研究单价；另计预制墩式基础与吊装80/120/180元/㎡经验估计。更衣淋浴洁具、补给售货设备、家具等另列在“设备”中。
  • 残值：模块用房和廊架可拆装、整体移动，用地到期后可搬迁再利用或转售，残值可按其造价的30%–50%估计经验估计（中值造价下约—万元）。为保守起见，残值不计入现金流和回收期。
  • 电力接入与箱变：40/60/90万元（约400kVA）经验估计；给排水接入5/10/20万元。
  • 工程建设其他费按工程费的10%计；场地条件未知，基本预备费按8%计；开办费20/30/50万元。
  • 多片共用围网和灯杆，有规模效应：场地工程约为每片—万元，低于单片独立建设的40万元中值。北京体育大学2026年18片改造项目控制价约77万元/片（政府项目口径，含拆除）可作上限参照。
