通州16片网球训练中心策划

选址参考点：北京市通州区潞邑街道孙各庄片区，通运路附近（WGS84 116.6973352E, 39.9277580N）。本项目为策划阶段，无用地红线，以下布局按假定的规整矩形用地编制。

用地 25亩（156.4×106.6m，约16,672㎡） 16片标准网球场 东西两区，每区8片（4×2） 中部配套带24m，配套楼约1,200㎡ 南侧场内停车78个小车位 + 2个大巴位 长轴南北向

结论：建议采用方案二：西区8片室外 + 东区8片气膜作为一期。西区同步预留气膜环形基础与电力容量，待东区利用率稳定在60%以上、用地年限明确后，再升级为方案三（16片全气膜）。基准情景（弹性丙烯酸、中值造价、利用率55%、租金5万元/亩/年）下，方案二总投资约—万元，年收入约—万元，EBITDA约—万元/年，静态回收期约—年。全室外的方案一冬季约3个月停业，EBITDA仅约—万元/年，回收期过长。方案三账面EBITDA最高（约—万元/年，回收期约—年），但需多投入约—万元，还要承担16片室内场的市场深度风险、气膜审批风险和夏季闷热问题。

两区各8片场地，每区东西向4片并列、南北向2排，两排端线外的缓冲区背靠背，共用一道端线围网。中部24m配套带布置配套楼、消防通道与回车场。南侧30.46m进深依次为：场前步道2.0m、6m双向车行道（兼消防车道）、双排垂直停车（5.5+6+5.5m），最南面是5.46m的临街绿带和入口广场。

布局复核与说明

  • 区宽：4×10.97 + 3×4.00 + 2×3.66 = 63.20m；区长：2×36.57 = 73.14m。两排背靠背布置时，相邻端线间距12.80m（6.40×2），满足ITF国际比赛推荐值。
  • 总宽：3.0 + 63.20 + 24.00 + 63.20 + 3.0 = 156.40m；总长：3.0 + 73.14 + 30.46 = 106.60m。南侧30.46m = 场前步道2.0 + 车行道6.0 + 停车5.5 + 通道6.0 + 停车5.5 + 临街绿带5.46。
  • 车位核算：西半区两排各21个标准位（2.5×5.5m）+ 1个无障碍位（3.7m宽），共44个；东半区北排先布2个大巴临停位（各13×3.5m，平行停放），剩余12个小车位，南排22个（其中最东8个为充电车位）。合计78个小车位，比给定的约80个少2个，原因是大巴位占去约10个小车位的长度。如需凑足80个，可把南侧临街绿带压缩到约3m并改为斜列停车，或把大巴位移到入口广场的落客车道上。
  • 消防：南侧6m车行道东西贯通，中部配套带西侧设4m消防车道，向北直达场地北端，北端设20×15m回车场（兼休闲广场），尽头式消防车道长约73m，按GB 50016的要求设回车场（≥12×12m，大型消防车≥18×18m，需复核）。配套楼两层，体量小，消防车道可沿其西侧长边布置。
  • 绿地率：本方案绿化约11.5%，明显低于北京多数地块控规要求的绿地率（常见20%–35%）。如果控规要求较高，可采用植草砖车位（部分地区可按一定比例计入）、把北侧3m带加宽，或减少车位。这一项必须拿到控规指标后复核，见第03节。
  • 朝向：所有场地长轴南北向，符合JGJ 31-2003第4.2.7条。地块如需旋转，可北偏西不超过10°、北偏东不超过5°。冬春季西北风强，北侧和西侧外围网挂30%–50%透风率的挡风布。

02前提与选址条件

区位（仅作参考）

参考点位于潞邑街道孙各庄片区，紧邻南北向的城市次干路通运路。东侧约200–400m是已入地的东六环（2025年4月隧道通车，地面改为六环高线公园）。东南约1.2km是副中心行政办公区北缘和潞城中心公园。周边主要是孙各庄棚改安置房、含章园等新建居住区。

  • 生源：1.5km内有北京五中通州校区（约450m）、北京第一实验学校、龙旺庄学校、北京小学通州分校，适合做青少年培训和校企场地共享。
  • 竞品：潞邑、潞城方向几乎没有直接对标的商业网球场。最近的气膜竞品是通州首家气膜运动馆（3片网球场，2025年12月开业）；城市绿心有6片室外场。
  • 坐标：国内地图使用GCJ-02/BD-09坐标，同一点在国内地图上大约要往东偏0.006°、往北偏0.0013°，核对点位时要先换算。
  • 东六环隧道：场地如果靠近隧道，打桩、开挖、堆载（包括气膜环形基础）需要满足隧道保护区要求，需向首发集团或市交通委核实。

规划注意事项

  • 用地性质：长期经营的网球场应落在体育用地（A4），或依规在公园绿地、公共服务设施用地、居住用地中兼容布置（《北京市体育设施专项规划（2018—2035年）》）。在绿地中建设应以室外、低硬化为主，不宜建封闭的永久室内馆。
  • 临时用地：孙各庄属潞城棚改片区，周边可能有储备地块。临时使用协议的期限常见3–5年（经验估计），这种情况下构筑物应尽量做成可拆装的（气膜、装配式钢结构、可移动灯杆）。
  • 副中心控规：需查地块所在街区的用地性质、容积率、绿地率和限高。地块距行政办公区约1km，气膜馆（2个4片膜跨度约37m，高约12–14m；1个8片膜跨度约63m，高约18–20m）的外观、夜景照明可能需要专项审查。
  • 审批：只建室外场时，一般走园林、城管或街道备案。建配套楼需办建设工程规划许可和施工许可；气膜在北京各区的审批口径不一，有的按临时建筑办理，并须做专项消防设计。
  • 邻避：周边以住宅、学校为主，建议22:00闭场，灯具采用截光型、防眩光产品；夜场击球声对北侧住宅的影响需评估。
  • 公益属性：在政府或国有土地上建设时，可能被要求保留公益开放时段或惠民价格，这会压低收入（测算未计入）。

使用年限长期自有、10年以上租赁，还是3–5年临时使用测算按10年计。若只有3–5年，三个方案在基准情景下都回不了本，应改用轻资产（只做室外场或租赁气膜），配套楼改用装配式。
室内外与冬季运营定位是否必须冬季运营；对气膜的接受度决定选方案一、二还是三。冬季停业会使方案一全年可订天数降到240天。
目标客群与培训定位大众订场、青少年培训、赛事承办的侧重；是否与学校或体校合作教学时段占比（测算取已售场时的40%）、私教单价和训练营期数是收入的最大变量。
投资上限与收益目标资金上限；目标回收期或IRR决定能否一次建成方案三，还是分期（先方案二、后加膜）。
运营模式自营、委托运营或出租给俱乐部出租模式下收入变为固定租金，人员成本和教练分成不再计入；自营的回报更高，风险也更大。

消防与交通开口可开口的城市道路及位置；消防车道和回车场要求本图假设南侧临路、东西两端各开一个车行口。如只能在东侧或西侧开口，停车和入口广场需整体翻转。
复合业态是否需要看台、中心场、匹克球、儿童区中心场需加宽到约40×20m并设看台，会占去1–2片场地或部分停车；匹克球可在错峰时段于网球场上划线兼用，不影响布局。
地块现状地形测绘、地勘、地下管线、拆迁或回填情况回填土需换填或加厚基层，场地单方造价可能上浮20%–40%；预备费已按8%计。

05关键假设与数据来源

运营假设

  • 营业：全年平均每片每天15个可售小时；室外可订240天经验估计，气膜350天。
  • 黄金时段占已售场时的65%；会员储值、平台团购等的综合折扣按8%计经验估计。室外已售场时中约30%需开灯，加收灯光费。
  • 定价：室外80/120元+灯光20元，气膜160/240元研究推荐值，参照朝阳体育中心室内160/240元、室外90/130元。
  • 教学：教学时段占已售场时的40%（基准下约为总可售场时的22%，上限35%）。其中一半为私教（400元/小时，场馆分成40%），一半为青少年小班（按5人×80元/人·小时，教练成本40%）经验估计。
  • 训练营：每期12人，人均2,000元（半日营和全日营混合），教练成本45%。方案一只有暑期营（期数×0.7），方案三×1.2经验估计。
  • 其他收入（零售、穿线、饮品、团建赛事、广告）按场租与培训收入的10%计，毛利率40%经验估计。
  • 人员（北京，含单位社保公积金）：总经理1人31万元、运营/市场2人共31.6万元、教学主管1人23.8万元、前台客服6人共63.6万元、场地维护与保洁6人共56.4万元、安保2人共18.8万元、财务行政1人12.7万元；每个气膜区另加设备运维1人12.7万元。社保按2026年度缴费基数下限7,270元计。
  • 能耗：室外LED照明每片约4kW，全年约1,000个开灯小时，电价约1.3元/kWh（夜间高峰）。每个8片气膜区：风机约6万元、照明约16万元（37kW×5,250h，按使用率折算）、燃气采暖约25万元（12–2月及春秋）、夏季通风除湿约5万元，合计约52万元/年经验估计，自下而上测算。研究资料给出的“每片15–30万元/年”是小型单片气膜的口径，大跨8片膜单片能耗明显更低，但仍需按厂家方案复核。配套楼水电燃气约18万元/年，室外照明与监控约2万元。
  • 面层维护：室外丙烯酸每5年重涂（约45元/㎡），气膜内每8年重涂，另加日常每片0.3万元/年；膜体与风机维保按膜体造价的1%/年。
  • 其他：保险1万元+工程费的0.2%；营销为收入的4%；平台佣金按40%场租走平台、费率7%，另加订场系统2万元；物业、环卫、绿化养护10万元；耗材每片0.6万元；设施日常维修为工程费的0.5%；税金及附加按收入的3%简化计算。不计所得税、折旧和融资成本。
  • 场地租金：默认5万元/亩/年（约75元/㎡/年），按25.01亩计约125万元/年。研究给出的基准值为7.3万元/亩/年，政策性用地可低至象征性水平。

投资假设

  • 场地构造：级配碎石15–20cm + 水泥稳定碎石15–20cm + 沥青混凝土5–6cm + 面层；按两区围网内全面积9,245㎡铺装（含场间空档）。
