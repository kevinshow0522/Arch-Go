# 建筑设计分析图（建筑单体）

建筑尺度分析图的主角是空间：讲空间怎么叠、怎么连、怎么用。Claude 负责在用户给的底图上叠分析层（颜色、流线、标签、图标、引线、数字）并做交互页面；不自造与模型不符的体量，室内透视和效果图交给 GPT。

## 工作流程

1. **确认这张图要讲什么**：对应工作流章节（见下表）、选哪个模板、重点空间是哪几处。一张图只讲一件事。
2. **要底图**：轴测类模板（B1、B2、B5、B8）必须用用户从 SketchUp 或 Rhino 导出的线稿；剖面类（B4、B7）用剖面导出；平面类（B3、B9）用 CAD 平面或总平；B6 可由 Claude 绘制。没有底图时可先用示意几何出版式，并在图上注明“示意几何｜正式出图叠在模型导出线稿上”。
3. **选配色**：每个项目一套（见“配色”）；用户给了配色标准用用户的，否则给几套参考让用户选，未选时默认 A。分析图和平面图纸用同一套颜色，同色同义。
4. **出静态图**，再按需做**交互页面**（HTML，发链接或给单个 .html 文件）。每个交互状态都能导出一张静态图，PDF 一状态一页。
5. **出图前校核**（见“校核清单”）。

读写用户本地项目文件夹前每次都先征得同意；原始资料取自“项目资料”，成果放“成果输出”，过程文件放“工作文件”。

## 模板 B1–B9（及候选 B10–B12）

模板不一次定全：不同项目分析的内容不同，模板跟着项目积累。用到新画法时先在项目里试，用户确认好用后再收进本表。标“候选”的模板还没有样板，第一次用时先画样板给用户看。

## 通用表达规则

- 底图越淡，分析层颜色越少；一张图通常只有一到两种饱和色。周边白模、本体灰白，只给要讲的东西上实色。
- 标签代替图例（线式标签：圆点＋引线＋名称）；颜色多于五六种时才加图例。
- 数字直接上图：标高▼、面积、百分比、间距。
- 颜色跨页同义：入口三角、功能色在流线图、分析图和平面图里含义一致。
- 叙事顺序：问题 → 概念 → 生成（3–6 步）→ 分项特色（一个亮点一页）→ 规划分析 → 技术图纸。

## 配色（取自日本传统色卡 nipponcolors）

**一个项目只用一套配色，03 场地分析和 05、06 同色同义。** 用户给了项目配色标准时以用户的为准；没有时从下表或色卡另取几套参考给用户选，不完全固定。建筑项目的场地分析也用本节配色，不用 urban-design-analysis 第四节的 A–D 风格。

配色随时可以增补和更替；用户嫌不好看时从色卡重新取色，不要自己凭空调色。中性色（画布、白模、线）可由色卡色加白或加黑得到。功能色固定六类，流线色固定三类。

## 底图导出要求（发给用户）

**SketchUp**：相机 → 平行投影 → 标准视图“等轴”，存为场景“分析机位”后不再转动；白背景，关天空地面，边线 1px，关轮廓线、延长线、端点；爆炸前另存一份模型，每层楼板连墙体编组，沿 Z 轴上移同一距离（1.5–2 倍层高）；文件 → 导出 → 二维图形，透明 PNG，宽 ≥4000px（Pro 版可导 PDF 矢量）；剖切轴测用剖切面＋剖面填充，同一场景导出。

**Rhino**：Parallel 投影，用 NamedView 保存机位；楼层分图层 F1、F2…，Move 沿 Z 爆炸；首选 Make2D 导出 SVG／AI／DWG 矢量（做交互最好）；带阴影材质用 ViewCaptureToFile 透明 PNG ≥4000px；剖切用 ClippingPlane。

**交给 Claude 的文件**：整体轴测一张；爆炸轴测一张＋每层单独一张（同机位同画幅）；生成序列每步一张；命名如 项目名_B2_F1.png；附一句说明：每层主要功能、要讲的重点空间、分时开放安排、面积数字。线稿上看不清的地方列出来问用户，不猜。

## 交互方案

| 模板 | 交互 |
| --- | --- |
| B1 | 逐步播放，新加体块从上方落下并着色；自动播放每步 1.6 秒；进度条可点 |
| B2 | 滑杆合拢↔拉开；点楼层名单独看；点功能只亮一类；切流线版，虚线流动 |
| B3 | 底图不动，高亮层淡入淡出切换 |
| B4 | 悬停色带，同类功能各层同时高亮；点圆形照片放大 |
| B5 | 按上课、放学后、周末、寒暑假切换开放房间和使用者气泡 |
| B6 | 滑杆在分区图和家具图之间过渡 |
| B7 | 节气按钮或滑杆调太阳高度角，实时算室内日照进深（进深 = 窗高 / tan(高度角) − 出挑）；风、光、雨分层开关 |
| B8 | 数字从 0 增长；悬停单层看占比 |
| B9 | 车行、人行、消防开关任意叠加，虚线流动 |

通用规则：一张图一个主控件，放在图正下方；悬停只突出（其余淡到约 20%）不弹窗，点击才切换，手机用点按；切换 0.3–0.6 秒缓入缓出，数字增长 1.2 秒；同一模板内机位、比例、底图不变；换配色不重置状态；键盘 ← → 翻步骤，1–9 跳模板；系统开启“减少动态效果”时直接跳到结果。交互页面做成自包含 HTML（SVG 叠在底图上），汇报时浏览器全屏；这些页面是 07 展示界面的内容。

## 校核清单（出图前必做）

成熟文本也常出错，每张图出图前逐项核对：
- 面积气泡、量化分层的分项相加等于合计，百分比的分母写明且算对。
- 同一符号同一颜色全套只有一个含义（例：红三角不能既是消防入口又是车行入口）。
- 图例覆盖图上所有颜色；图名与内容一致。
- 中英文对应、无拼写错误（常见：Project、Accommodation、classroom、Special、Faculty、playground、Public）。
- 太阳高度角、标高、尺寸与项目数据一致；体量与模型一致，没有自造。
