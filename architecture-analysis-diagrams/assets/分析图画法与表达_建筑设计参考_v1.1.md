## 一、总判断：建筑尺度的分析图，主角从“地图”换成了“空间”

城市设计分析图以平面地图为底，讲系统和结构；这四份建筑文本里，真正讲空间的图几乎都离开了平面，换成五种三维或剖切载体：

| 载体 | 回答的问题 | 典型页 |
| --- | --- | --- |
| **爆炸轴测**（竖向拆层） | 每层放什么、层与层怎么对位、竖向怎么贯通 | 前海p25、p26；中科院p66、p81；宝龙p16、p22 |
| **剖切轴测**（切掉屋面看一层） | 一层里的房间、家具、使用场景和开放范围 | 前海p30、p39、p52；宝龙p10、p14 |
| **长剖面／剖透视** | 高差、台地、上下叠合、公共层与地下空间、气候原理 | 前海p29、p76；中科院p76；宝龙p6；吉华p21、p22 |
| **同机位轴测序列** | 形体怎样一步步生成 | 前海p24；吉华p15；宝龙p4 |
| **成对平面**（分区图＋家具图） | 一个房间单元怎样被灵活使用 | 前海p40–48、p53–59 |

平面仍然用，但只承担两类任务：**总图层面的流线、间距、日照**（前海p27；吉华p25–27；宝龙p23），以及**技术图纸**。

一句话：**讲“是什么、在哪里”用平面，讲“空间怎么叠、怎么连、怎么用”用轴测和剖面。**

## 二、按类别的画法

### 2.1 流线分析

四份文本里有三种做法，从二维到三维：

**A. 同底多联平面（最常用，交通管理用）**
- 前海p27：车行／人行／消防三张**同底、同裁切**平面并排。底图只画灰色线框（建筑、跑道、街块轮廓），不填色。
- 每一类流线一种颜色；**实线＝地面，虚线＝进入地下或桥下**；线端空心圆＝停靠点或入口；场地外放同色交通工具图标（校车、公交、私家车、消防车）。
- 人行图里**按入口类型分色**（红＝主入口、橙＝对社会开放、蓝＝教职工次入口），家长等候区画成一段粗的浅红色带。消防图：红线＝消防车道，红框＝登高面。
- 吉华p26、宝龙p23同理：人行绿、车行深蓝紫、后勤橙黄、消防红虚线。
- 中科院p51：左人行（橙，主流线粗、次流线细、景观流线虚线，建筑入口＝小圆点）右车行（蓝，P图标、地库入口蓝色矩形）。

**B. 流线叠在剖切轴测上（讲楼上楼下）**
- 宝龙p14：功能组团半透明着色，**深蓝实线＝楼面层人行流线，红虚线＝地面层人行流线**——用实／虚区分标高层。
- 宝龙p12、吉华p25右：接送流线，**地下接送中心＝蓝色半透明块＋蓝虚线轮廓**（表示“在地下”）。

**C. 流线穿过爆炸轴测（讲竖向组织，最能表达立体校园）**
- 前海p26：把功能爆炸图整体**淡化成浅色幽灵体块**，只让流线饱和：中学生路线深品红、小学生路线粉红、内部活动流线深蓝；层间用**带箭头的竖直线**连通；楼梯、扶梯处放品红圆形图标；等候区用三种斜线填充区分（家长／驾车／校车）。

**规律**：流线图的底图一定比别的图更淡；流线是全图唯一的饱和元素；“谁走哪条线”按使用者分色，“在哪一层”用实虚区分。

### 2.2 功能分析

**A. 面积气泡（任务书阶段）**
- 中科院p43、前海p21：按大类分列（竖虚线分隔），圆的大小表示面积，每圆写中文＋英文＋面积，列底写合计。
- 前海p22：把同样的气泡按“中学组团—活力中心—小学组团”的空间关系重新排布，外围虚线圈＋底下半透明色带环——从“清单”变成“关系”。
- 宝龙p22左：把任务书画成**清单图**：大色块＝类别，“＋”号后面的虚线框里按比例画小方块，每块写房间名和间数（美术教室2间…）；运动场地用线稿图标＋个数。

**B. 功能轴测（单体落位）**
- 前海p25：整栋楼竖向爆炸，屋顶跑道、环形教学层、首层与地下层上下拆开，**灰色细虚线竖向对位**，楼层名称沿轴测方向斜写在楼板外（“首层 GROUND LEVEL”），体块按功能着色，文字沿体块方向旋转。右下双语色块图例。
- 宝龙p22右：五层爆炸，**线稿＋功能淡彩**，标签放在左右两侧，长虚线引线指到层内具体位置——比图例更直观。
- 中科院p55：周边白模、基地浅绿等高线，建筑按功能淡彩；**顶部和底部各一排黑色圆形图标＋名称，竖向细引线落到建筑**。吉华p24右用同样方法（橙色圆形图标在顶，虚线落位）。

**C. 规划结构与功能成对**
- 吉华p24：**同一鸟瞰机位左右并排**。左“规划结构”：建筑统一成浅青透明体块，轴＝半透明斜纹宽带＋大箭头，环＝深蓝宽带箭头，中文粗体标签放带端、英文白字沿带写；右“功能分析”：同一体块按功能上饱和色。

### 2.3 空间分析（重点）

**A. 爆炸轴测讲“竖向叠合”**
- 中科院p66、p81：左边淡化卫星图上开“放大镜”圆（圆内原色、圆外白色遮罩）或把该建筑品红高亮；右边爆炸轴测：上部体块浮起，竖虚线对位，下层落在**切成圆柱的地形块**上（侧面露出土层）；中庭贯通画成一根浅蓝竖向光柱。
- 标注不用图例，用**线式标签**：层名＋水平线＋端点圆点落到该层；活动用黑色圆形图标＋中英文。

**B. 同底系列讲“某一种空间”**
- 前海p34–36：同一张灰白楼层轴测，**每页只把一种空间涂成一种实色**——学术长廊橙、交流平台黄、共享客厅蓝；沿该空间放3个一组的同色圆形活动图标，用竖向虚线落位；右侧配该空间的抽象符号和说明，左下一张效果图。
- 前海p33先用“L／M／S”三个大字母＋同色符号建立这三类空间的图形系统，后面三页逐一展开。这是轴测版的“同底四联”。

**C. 剖切轴测讲“空间被怎样使用”**
- 前海p30：切到该层，房间家具可见，按功能填色（图书馆橙、球场蓝绿、剧场紫），每个功能一个彩色圆形图标；**师生对话写在白色对话气泡里**（“学生A：这个题有什么更好的解法吗？”），用场景说明空间用途。
- 宝龙p10：只把对社区开放的房间涂成饱和色（报告厅红、篮球馆橙、食堂粉），其余浅灰；右上小轴测用三种绿色区分**“周末开放／寒暑假开放／放学开放”**——分时开放图。

**D. 长剖面讲“上下关系”**
- 前海p29、中科院p76、宝龙p6上：**功能色带剖面**——每层楼板一条色带，功能名用超大字直接写进色带当填充（GYMNASIUM体育馆、CANTEEN餐厅、PARKING GARAGE停车区）；地下整块浅灰；上下两排**圆形照片用细竖线落到剖面位置**（重点空间圆更大）；下方用细线括号分出组团。
- 宝龙p6下：同一位置再画一张**渲染剖透视**（剖切线粗黑、室内可见、车库画车）。一张讲逻辑，一张讲体验。
- 吉华p21：渲染剖透视（灰色城市背景）上压一条**品红虚线双向箭头＋品红大字“社区共享／可对周边市民开放”**——在写实剖面上只叠一种颜色讲一件事。
- 宝龙p15：三个黑色剖面剪影演变（封闭→架空→打开），讲“向城市打开”。

**E. 房间单元讲“灵活性”**
- 前海p40：上排三句大字推导（行为特点→安全与灵活→内外共享），用浅到深的渐变箭头连接；下排四个圆角小平面（常规／开放／讲座／主题模式）：绿＝阳台、浅蓝＝教室、米色＝走廊，蓝与米色之间用**渐变**表示边界被打开，橙色虚线弧箭头＝活动走向。
- 前海p41等：一页两张同一平面——左**分区图**（半透明色块分区，品红双向箭头跨越边界＝可打开），右**去色家具图**（文字块用红虚线引线指到位置），尺寸、轴线齐全。
- 前海p42等：对应的**线稿淡彩室内透视**（只给椅子上绿色，白色剪影人），左上角小平面＋黄色视角扇形。

### 2.4 设计生成

三份文本都用同一套路，可直接做模板：
- **同一轴测机位、周边白模只画灰线或浅灰、用地红点划线**；4格（2×2）或6格（2×3）。
- **每步只把新加的东西着色**：前海p24（彩色楼板叠层→跑道红色＋“抬起运动场”大箭头→粉色环＋黄色圆环→回到白模＋绿化）；吉华p15（蓝色双轴宽带→蓝色书院体块→蓝色学环＋红色跌落箭头→红色艺术学村）；宝龙p4（标高三角→绿色三级台地→四色功能体块＋灰色标签牌→流线→树、太阳、视线→活动图标）。
- 每格下：**大号编号＋短名＋一句中文＋英文**。宝龙用超大橙色数字。
- 前海p16、p18用更简的**图标剖面前后对比**：黑竖条＝楼、绿横线＝运动场，上“问题”下“方案”，中间黑色大箭头。

### 2.5 场地与问题

- 前海p14：**问题三联**，三张同尺寸图：白模＋红虚线基地里一个巨大黑色“？”；灰色卫星图＋服务半径同心圆（粉1000m、蓝500m）；同一白模底里用黑条块＋灰跑道＋细绿条直观表现“绿化不足”。
- 吉华p11–12：问句标题（关键词蓝色）＋照片拼贴＋底部一句口号回答；客家围屋四张照片各提取一个空间特征（向心的形态／开阔的广场／便捷的联系／有序的布局）——“原型→空间特征”。
- 中科院p30：左三张环境视角白模（周边楼淡紫＋紫描边、▼标高），右浅暖底平面：红色宽带“沿街界面”（字沿带排）、红色渐隐箭头“场地入口”、绿色弧形宽箭头“引入城市绿轴”，紫色编号圆对应左侧视角。
- 宝龙p3：黑白卫星底＋绿色半透明山林＋红色基地，单色强调。

### 2.6 绿色与气候

- 前海p76：同一教室剖透视竖向叠三张（夏季采光、冬季采光、通风），楼板墙体涂实黑；**夏季太阳高、射线陡（橙红），冬季太阳低、射线斜（橙黄）**；通风画成几十根细线组成的**蓝→绿→黄渐变丝带**穿过教室。
- 吉华p22：四张线稿小轴测（庭院／天井／连廊／冷巷）——蓝色宽丝带＝冷风进、红色细箭头＝热气升；下方通长剖透视：太阳＋黄色斜线＝遮阳，绿色上升弯箭头＝拔风，蓝色水平箭头＝架空通风。
- 前海p74：功能色带剖面＋水循环（蓝色虚线管、收集／过滤水箱）＋圆形放大图。中科院p125同法。

### 2.7 量化与技术

- 宝龙p16：**活动空间最大化**——上下错开两层轴测，四类活动场地分别编号，每个配圆形照片＋大号百分比＋面积；左侧竖向色柱；大字结论“室外活动覆盖110%”。核算：4482＋4600＋4215＋645＝13942㎡，13942÷12737＝109.5%，数字自洽。
- 吉华p25：建筑间距——深灰粗尺寸线＋端头短线＋粗体大数字（32m、53m、71m、95m）。
- 吉华p27、宝龙p23：日照、采光直接用软件输出图（彩色网格＋色标）。宝龙p23附完整说明：依据《深圳市建筑设计规则》4.3.2.2、软件、经纬度、冬至日9:00–15:00、间隔5分钟、结论“普通教室满窗日照不少于冬至日2小时”。
- 中科院p56、前海p28：天际线——轴测屋面按高度用**蓝色顺序色阶**（<20／20–30／30–40／>40m）＋弧形箭头。

### 2.8 概念隐喻（慎用）

- 前海p20：黑底上把机械表机芯爆炸成四个环（运动／实践／学习／生活），环名沿圆弧排字。
- 中科院p38：模数图案＋3×3形态变体矩阵（大平面／院落／裙房／切割／阶梯／塔楼／叠加／搭接／塔院），灰白体块＋紫色描边——**形态可能性矩阵**，比隐喻图更有用。
- 这类图不表达真实空间，一个项目一两张即可。

## 三、表达风格与样式

### 3.1 四份文本的风格对照

| | 前海（HENN＋中建） | 中科院（HENN） | 吉华（华艺） | 宝龙（库博） |
| --- | --- | --- | --- | --- |
| 整体 | 白底、大留白、饱和多彩 | 白底、大留白、淡彩 | 白底、版面满、写实为主 | 白底、线稿为主 |
| 主色 | 品红、橙红、黄、蓝、绿 | 紫（品牌）、青（页码）、品红 | 蓝、红、橙 | 橙黄（章节）、绿 |
| 底图 | 灰白轴测、灰线平面 | 淡化卫星、白模、绿色等高线地形 | 白模鸟瞰、写实剖透视 | 白色线稿轴测、灰色水墨卫星 |
| 招牌图 | 爆炸功能＋流线、同底空间系列、教室模式 | 放大镜＋爆炸地形块、功能色带剖面 | 规划结构／功能成对、气候四件套 | 量化分层、分时开放、清单图 |
| 母题 | 跑道形、彩虹平行线、圆环扉页 | 三角＋圆弧、知识网络 | 围屋、学环 | 森林绿毯 |

### 3.2 共同的样式规律

1. **底图越淡，分析层越少色。** 一张图通常只有一到两种饱和色，其他全部灰白或淡彩。流线图最极端：体块淡成幽灵，只有线是饱和的（前海p26）。
2. **白模＋单色高亮**是最通用的语法：周边白模、本体灰白，只把这页要讲的东西涂实色（前海p34–36、吉华p17、宝龙p10）。
3. **颜色跨页同义**做得最好的是前海：入口三角在流线图和首层平面里同色同义（红主入口、橙校车、绿公交、蓝次入口，p27＝p81）。
4. **圆形照片＋细引线**四份都用：照片圆放在图的上下或右侧，细竖线或点线落到具体位置，端点小圆点。它把“空间位置”和“空间体验”连起来，是建筑分析图最常见的组合方式。
5. **黑色或彩色圆形图标**表示活动和功能，排成一排或3个一组，用竖虚线落位（中科院p55、前海p34、吉华p24）。
6. **标签代替图例**：线式标签（名称＋横线＋圆点）、斜写在楼板上的层名、写进色带的超大功能名。图例只在颜色多于五六种时出现。
7. **数字直接上图**：标高▼、间距大数字、面积、百分比。
8. **叙事用大字**：设计挑战、问句、口号用黑体大字（中科院关键词品红高亮，吉华关键词蓝色，宝龙关键句橙色）。

### 3.3 版式

- **页眉**：前海／中科院＝左上两行中文（章／页名）＋英文章名＋粗体页名；吉华＝“章名｜英文章名”＋下一行本章小节面包屑；宝龙＝橙色小标签＋英文大标题＋橙色中文大标题。
- **页脚**：项目中英文名；中科院右下青色“编号＋图名”。
- **扉页**：前海用大圆环母题，每个理念章节一种颜色（立体沟通校园粉、趣味教育空间浅蓝）。

## 五、叙事顺序

四份文本都按同一条线组织，分析图是链条上的环节，不是独立的图：

**问题（场地／教育／气候）→ 概念（公式或口号）→ 生成（3–6步）→ 分项特色（每个亮点一页：轴测＋照片＋效果图）→ 规划分析（结构／功能／流线／间距／日照）→ 技术图纸**

- 前海：三个理念各成一章（立体沟通校园／趣味教育空间／绿色建筑），每章扉页一种颜色。
- 吉华：“六大亮点”页先总览（6张效果图＋编号色条），后面一页一个亮点。
- 概念公式：照片＋照片＋照片＝主题（吉华p10、前海p63、中科院p41）。

## 七、对我们工作流的建议（待讨论）

以下是根据本次学习提出的建议，尚未确认：

1. **建筑单体分析单独成一套方法**（与城市设计分析并列），核心载体：爆炸轴测、剖切轴测、功能色带剖面、同机位生成序列、成对平面。
2. **可沉淀的建筑尺度模板**（编号暂定B）：
   - B1 同机位生成序列（4或6格，每步只着色新加部分）
   - B2 爆炸功能轴测＋同图流线版（先功能，后把体块淡化画流线）
   - B3 同底空间系列（一页一种空间、一种颜色）
   - B4 功能色带剖面＋圆形照片引线（可配同位置渲染剖透视）
   - B5 剖切轴测＋使用场景（对话气泡、分时开放）
   - B6 房间单元模式（推导三句＋模式小平面＋分区图／家具图对＋透视）
   - B7 气候策略（剖透视三联或四件套＋总剖面）
   - B8 量化分层（编号＋照片＋百分比＋面积，数字必须闭合）
   - B9 同底多联流线平面（车行／人行／消防）
3. **对应工作流章节**：05.2总平布局→B1、B9；05.3功能分区→气泡、B2；05.4交通流线→B9、B2流线版；05.5体量与剖面→B4、爆炸轴测；05.6环境回应→B7；05.8重点空间→B3、B5、B6；06.2平面功能→淡彩平面＋编号图例；06.3剖面→poché剖面＋色带剖面。
4. **底图来源**：爆炸轴测、剖切轴测需要用户从SketchUp或Rhino导出的白模线稿；Claude负责叠分析层、标签、图标和引线，不自造与模型不符的体量。
5. **颜色**：沿用“每个项目选一组配色”的原则；建筑尺度需要增加一组**功能色**（教室、专业教室、公共、体育、办公后勤、宿舍），并保证分析图与平面图纸同色同义。

## 八、v1.1 已定（2026-10-19）

1. **模板由 Claude 制定**：B1–B9 九个模板全部保留，样板见“建筑分析图模板 B1–B9”页面。

## 九、交互方案（2026-10-19）

每个模板配一种交互，用于 07 展示界面和屏幕汇报，样板见“分析图交互方案”页面：

| 模板 | 交互 |
| --- | --- |
| B1 生成序列 | 逐步播放，新加体块从上方落下并着色；自动播放每步 1.6 秒；进度条可点 |
| B2 爆炸轴测 | 滑杆合拢↔拉开；点楼层单独看；点功能只亮一类；切流线版，虚线流动 |
| B3 同底空间系列 | 底图不动，高亮层淡入淡出切换 |
| B4 色带剖面 | 悬停色带，同类功能各层同时高亮；点圆形照片放大 |
| B5 剖切轴测 | 按上课、放学后、周末、寒暑假切换开放房间和使用者气泡 |
| B6 房间单元 | 滑杆在分区图和家具图之间过渡 |
| B7 气候剖面 | 节气按钮或滑杆调太阳高度角，实时算室内日照进深；风、光、雨分层开关 |
| B8 量化分层 | 数字从 0 增长；悬停单层看占比 |
| B9 多联流线 | 车行、人行、消防开关任意叠加，虚线流动 |

通用规则：一张图一个主控件，放在图下方；悬停只突出不弹窗，点击才切换；切换 0.3–0.6 秒；底图和机位不变；每个交互状态对应一张静态图，PDF 一状态一页；换配色不重置状态；← → 翻步骤，1–9 跳模板；尊重“减少动态效果”。
