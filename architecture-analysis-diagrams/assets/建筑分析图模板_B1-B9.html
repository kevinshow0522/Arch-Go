建筑分析图模板 B1–B9

五套配色，全部取自日本传统色卡，之后可以随时增补和更替，每套一组底色、模型色、功能色和流线色，九个模板都能切换。图里的体量是示意几何，用来定版式和配色；爆炸轴测、剖切轴测、生成序列和量化分层正式出图时，底图用你从 SketchUp 或 Rhino 导出的线稿，我只在上面叠颜色、流线、标签和引线。

爆炸图和轴测底图的导出要求

所有轴测类模板共用一个机位。机位定一次，整套文本都用它，这样生成序列、爆炸图、剖切轴测才能逐页对得上。

SketchUp

  1. 相机 → 平行投影，相机 → 标准视图 → 等轴，再用场景保存为“分析机位”，之后不要再转动。
  2. 样式：白背景，关掉天空和地面；边线 1px，关掉轮廓线、延长线和端点；面用“隐藏线”或“单色”。
  3. 爆炸：另存一份模型再动手。每层楼板连同上面的墙体编组，按层沿蓝轴（Z）上移同一距离，建议取 1.5 到 2 倍层高。
  4. 导出：文件 → 导出 → 二维图形，PNG 透明背景，宽度至少 4000px。Pro 版可同时导出 PDF 矢量。
  5. 剖切轴测：在要讲的楼层上方放剖切面，打开剖面填充，用同一场景导出。

Rhino

  1. 视图设为 Parallel 投影，调好角度后用 NamedView 保存机位。
  2. 楼层分图层，命名 F1、F2…；爆炸用 Move 沿 Z 轴移动同一距离。
  3. 首选 Make2D 导出 AI、SVG 或 DWG 线稿，矢量最好叠层。
  4. 要带阴影或材质时用 ViewCaptureToFile 导出透明 PNG，宽度至少 4000px。
  5. 剖切轴测用 ClippingPlane，保持同一个 NamedView。

交给我的文件

  1. 整体轴测一张（不爆炸）。
  2. 爆炸轴测一张，另外每层单独一张，同一机位、同一画幅，方便逐层上色。
  3. 生成序列每一步一张，同一机位。
  4. 文件名：项目名_B2_F1.png、项目名_B1_步骤2.png。
  5. 附一句说明：每层主要功能，以及哪几处空间是这次要讲的重点。

我不会改动或补画模型里没有的体量。线稿上看不清的地方，我会列出来问你。
