# Claude Skills

建筑与城市设计分析图、场地建模相关的 skill。

| Skill | 说明 |
| --- | --- |
| [architecture-analysis-diagrams](architecture-analysis-diagrams/SKILL.md) | 建筑单体分析图：B1–B9 模板、日本传统色卡配色、模型导出底图要求、交互规则和出图校核 |
| [urban-design-analysis](urban-design-analysis/SKILL.md) | 城市设计分析图 v1.1：底图、配色风格、符号、模板、SVG 分层、交互展示（07.2）和校核清单 |
| [Map to Model](map2model/SKILL.md) | 地图／影像或 CAD 整理为前期建模底图，支持局部米制坐标、DWG 回读与 SketchUp 封面（v0.9.12） |

## 使用

把需要的 skill 文件夹放进 `~/.claude/skills/`，或在 claude.ai 的 Skills 设置里上传对应文件夹。
